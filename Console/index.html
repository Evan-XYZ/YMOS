YMOS Console

Reader 与决策台

一个本地入口，做三件事：翻报告、定计划、过门禁。 Reader 负责把产出聚到眼前；两个决策台负责在最容易犯错的时刻，把流程摆在你面前。

填的东西都写回你自己的 Obsidian，是纯 Markdown。没有数据库，没有云端，没有账号。

检查 vault 连接中…
改了 config.json / rules.json / .env 或更新代码后，点它生效（几秒后自动刷新）
按钮点不动、或控制台卡死了？在终端里手动重来：
关闭：pkill -f "python3 server.py"（或在运行它的终端窗口按 Ctrl-C）
重开：python3 server.py（在 Console 目录下）
懒得碰命令行？把这句话发给你的 AI Agent：「帮我重启 YMOS Console」

这几个页面都是可修改的样板，不是标准答案。 你可以让自己的 Agent / 编程工具根据目录结构、投资周期、风险偏好和操作习惯继续改造。 Reader 的分组在 config.json；决策规则在 rules.json；数据源 Key 写在 .env。
要接自己的 vault：复制 config.example.json 为 config.json，填上路径，然后 python3 server.py。
