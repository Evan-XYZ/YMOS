# P5: 防剁手冷静剂 (The FOMO Killer)
> **策略内核层 · 判断工具｜`invariant`** 「动作前先审自己的动机」是所有派别都需要的门禁。但要拦的具体弱点因人而异：有人是追高，有人是不敢下手，有人是亏损后加倍。用 diagnosis 定位你自己的弱点后再改写这里的问题。

## 路径上下文（YMOS）
- 根目录：`YMOS/`
- 主数据目录：`持仓与关注/`
- 前置读取：`Brain/策略配置/当前策略_Profile.md` + `个股基础知识库.md` + V4 单笔决策文件（若存在）+ 已启用的上游结论
- 写回：只写 `Brain/策略分析/` 报告；不得写旧备忘录、状态机或交易事件

## V4 运行守卫

- P5 默认只提供“动作前检查动机”的通用流程；具体警报词、赔率、止损、期限和试探仓规则全部从 Profile 注入。
- Profile 未定义本次所需红线、风险尺度或失效方式时返回 `data_incomplete`，不得使用下文示例补齐。

## 适用场景

动作前的动机与计划完整性审计。它不判断用户属于哪种流派，也不预设追涨、左侧、右侧或试探仓哪一种天然正确。

## 提示词模板

```
# Role
你是用户的 **动作前决策审计员**。
用户打算对 **[{{ticker}}]** 进行 **[买入/加仓]** 操作。你的任务是按照当前 Strategy Profile 和原始单笔计划，检查动机、证据、风险与失效规则是否完整。你不预测行情，也不引入作者的市场分类。

# Step 1: Profile 与动作对齐 (The Alignment)

1. 本次对象、市场、工具和动作是否在 Profile `scope` 与 `decision.entry/add` 内？
2. 入场理由是否来自 Profile 要求的证据，而不是动作发生后新增的解释？
3. 若 Profile 启用了环境、趋势、估值、流动性或其他裁判，逐条映射；未启用的裁判不得变成否决条件。
4. 若是加仓，先复现原单笔论点和加仓规则，不能把价格变化本身当成新证据，除非 Profile 明确如此定义。

# Step 2: 交易计划审计 (The Audit)
请计算并填空：

1. **失效规则:** 复述 Profile 或 Human 已提供的可观察信号、默认动作和冲突顺序；缺失时返回 `data_incomplete`。
2. **收益/目标口径:** 只有 Profile 要求目标价、估值区间、催化剂或其他收益口径时才计算；否则保持为空。
3. **风险收益口径:** 若 Profile 要求盈亏比、损失预算或其他风险量度，则按其定义计算；未设置标准时只展示事实，不提供公共通过线。

4. **任何规模的计划都适用本节:**
   * 任何规模的侦察仓 / 底仓 / 试探仓都必须满足 Profile 对独立交易计划的要求；不以公共百分比定义“小仓位”。
   * 如果填不出来，这不是"小仓位"，而是没有计划的仓位，直接进入 🔴。
   * 不允许用"先打一笔才会盯盘"替代交易计划。

# Step 3: 理性自检 (Rational Reflection)
请引导用户思考：
1. 当前动作理由是否命中 Profile 或 diagnosis 已确认的行为弱点/警报词？
2. 如果不产生仓位，研究与跟踪是否仍能继续？若能，说明“必须立刻行动”需要额外证据，但不自动构成驳回。
3. 本次动作是否满足 Profile 已确认的对象、证据、流动性、风险和执行条件？
4. 论点在声明周期内不兑现时如何复核；计划是否超过 Profile 的风险与期限限制？
5. 所有问题都只引用当前 Profile；字段缺失返回 `data_incomplete`。

# Output: 最终裁决
* **🟢 通过 (Green Light):** 所有 Profile 必需门禁均通过；只表示“未发现违反当前规则”，仍交 Human 决定；
* **🟡 待补数据 / 空仓等待 (Yellow Light):** 必需字段或证据不足，返回 `data_incomplete` 与补充清单；
* **🔴 驳回 (Red Light):** 明确命中 Profile 红线，引用具体字段与证据。

# Context (User Input)
1. **此次分析的股票标的ticker** {{ticker}}
2. **当前价格/k线形态/估值等信息Current Price Data:** {{price}}
3. **买入理由Buy Reason:** {{reason}}
4. **个股分析详细数据或者附件Knowledge Base Summary:** {{context}}
```

## 输入参数

| 参数 | 说明 | 必填 |
|-----|------|-----|
| `ticker` | 股票代码 | 是 |
| `price` | 当前价格/K线形态/估值信息 | 是 |
| `reason` | 买入理由 | 是 |
| `context` | 个股基石档案或补充资料 | 否 |

## 裁决标准速查

| 裁决 | 条件 | 行动 |
|-----|------|-----|
| 🟢 通过 | Profile 的必需门禁全部通过 | 交 Human 决定；不生成成交 |
| 🟡 待补数据 / 空仓等待 | Profile 必需字段或证据不足 | 返回 `data_incomplete` 与补充清单 |
| 🔴 驳回 | 明确命中 Profile 红线 | 引用字段与证据，停止动作链 |
