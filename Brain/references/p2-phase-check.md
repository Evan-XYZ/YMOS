# P2: 市场阶段定性 (PVP vs PVE)
> **策略内核层 · 判断工具｜`profile`** PVE/PVP 是作者用来定性「收益来自增量还是来自对手盘」的判断轴。只有 Profile 在 `modules.enabled` 中显式启用 P2，或通过 `replacements` 指向它时才执行；系统不预设 Beta / Alpha 的优先顺序。

## 路径上下文（YMOS）
- 根目录：`YMOS/`
- 主数据目录：`持仓与关注/`
- 读取：`动态Watchlist/{ticker}/个股基础知识库.md` 或 `持仓/{ticker}/个股基础知识库.md`
- 必须读取：`Brain/策略配置/当前策略_Profile.md`
- 可选读取：V4 单笔决策文件、当前事实与既有知识库
- 写回：默认只写 `Brain/策略分析/` 报告；从 `SOP_初始调研.md` 调用时可按该 SOP 写知识库增量；不得写旧备忘录或状态机

## V4 运行守卫

- Profile 未启用 P2 时返回 `module_not_configured`，不得按作者 PVE/PVP 语义继续。
- Profile 未定义环境与标的谁优先、所需观察信号或冲突处理时返回 `data_incomplete`。
- 下文的 MA20、资金流、PVE/PVP 和 SOP1/2 均是作者方法说明，不是公共门槛；只使用 Profile 已确认的字段。

## 适用场景

判断当前市场战场性质，以便匹配合适的投资策略。PVE 对应长持策略，PVP 对应短期交易。

> ⚠️ **层级顺序（Profile 级选择）**
> 本模块不提供默认顺序。只有 Profile 明确采用 Beta 优先时才先判板块；采用 Alpha 优先或其他替代顺序时按 Profile 执行。
> 这是一个可替换的顺序选择，不是普遍真理：自下而上的选股派完全可以反过来，先确认标的本身，再用环境决定仓位大小而非是否参与。
> 在你的 Strategy Profile 里写明你采用哪种顺序，以及冲突时谁优先。
>
> - PVE = 增量市场，环境提供顺风
> - PVP = 存量厮杀，收益主要来自对手盘而非增量

# Evaluation Framework

## 维度 A: PVE 特征扫描 (环境共识 / 增量市场)

> **关键问题：这个板块的「电梯」是向上的吗？**

* **板块 Beta 检查:**
  * 板块指数/ETF 是否满足 Profile 定义的趋势或环境信号？未定义则标记 `data_incomplete`。
  * 是否有明确的增量资金流入（北向/机构持仓增加）？
  * **顺序约束**：若 Profile 采用 Beta 优先，则板块 Beta 向下时不进入个股 Alpha 检索；若采用 Alpha 优先，则改为用 Beta 调整仓位上限。两种都要写明，不能临场切换。
* **驱动力：** 是否由业绩增长、基本面改善或宏观利好驱动？
* **资金流：** 是否有增量资金/机构大资金持续流入迹象（量价配合健康）？
* **常见信号：** 业绩兑现（Beat and Raise）、核心叙事稳固成长等。
* **策略匹配：** 适合 SOP 1（长期持有/坐得稳）。

## 维度 B: PVP 特征扫描 (存量博弈 / 价格战厮杀)

> **关键问题：这个板块是不是在「互相抢饭碗」？**

* **板块性质检查:**
  * 行业是否进入价格战/存量竞争阶段？
  * 玩家之间是零和博弈还是共同做大蛋糕？
  * **典型 PVP 形态**：行业渗透率见顶后进入份额争夺，龙头主动降价、全行业毛利率同步下移、销量增长但利润不增——此时收益主要来自对手盘而非行业增量。
* **驱动力：** 是否由情绪、叙事、谣言或短期资金博弈驱动？
* **交易特征：** 是否存在"利好出货"、"情绪过热"或"存量互割"现象？
* **策略匹配：** 适合 SOP 2（波段交易/跑得快）。关注点在情绪和 K 线，势能破位即止损。

## 维度 C: 筹码博弈扫描 (2026-03 新增)

> **关键问题：此刻谁在买、谁在卖、他们的动机是什么？**

这是在财报/销量等事件触发时最关键的一步——不分析公司，分析人。

**多头阵营识别（谁在买/持有）：**
* 买入动机是什么？（低估值抄底 / 叙事信仰 / 技术突破 / 被动指数配置）
* 他们的止盈逻辑是什么？（到哪个价位或事件会卖？）
* 这批多头的"韧性"如何？（散户情绪盘 vs 机构价值配置）

**空头阵营识别（谁在卖/做空）：**
* 卖出动机是什么？（财报不及预期 / 估值偏高解套 / 行业逻辑破坏 / 对冲基金结构性做空）
* 他们的止损逻辑是什么？（什么数据出来会被迫回补？）
* 空头压力是短期还是结构性的？

**筹码结构判断：**
* 当前是"利好出货"（主力借消息派发）还是"利好接力"（增量资金进场）？
* 换手率信号：高换手 = 博弈激烈；低换手 = 筹码稳定或无人问津
* 短期博弈的关键价位（多空分歧点）在哪里？

**情景 1：超预期（Bull Case）**

* 仓位策略：止损线在哪，是否执行？

* 触发条件：数据OK但前景不明朗

## PVP vs PVE 速查

| 维度 | PVE (共识/趋势) | PVP (博弈/存量) |
|-----|----------------|----------------|
| 驱动力 | 业绩增长、基本面改善 | 情绪、叙事、短期资金 |
| 资金流 | 增量资金持续流入 | 存量互割 |
| 信号 | Beat and Raise | 利好出货 |
| 策略 | SOP 1 长期持有 | SOP 2 波段交易 |
