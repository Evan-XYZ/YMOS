# P7: 投资组合检查与仓位再平衡 (Portfolio Check)
> **策略内核层 · 判断工具｜`invariant`** 「定期检查组合层面的集中度、相关性与敞口」是通用的。但资产分类方式和各类目标比例完全由你的 Profile 决定，本模块不提供任何推荐配置。

## 路径上下文（YMOS）
- 根目录：`YMOS/`
- 主数据目录：`持仓与关注/`
- 前置读取：`Brain/策略配置/当前策略_Profile.md` + `portfolioSnapshot` + 告警关联的 V4 单笔决策文件
- 写回：只写 `Brain/策略分析/` 组合报告；不得写旧备忘录、状态机或交易事件

Profile 未定义资产分类、目标、集中度/相关性口径或必要风险字段时，只报告当前结构并返回 `data_incomplete`，不得生成再平衡动作。

## 适用场景

投资组合健康度检查与仓位再平衡。检查 Profile 已定义的分类、集中度、相关性、期限和流动性约束；不提供公共目标配置。

## 提示词模板

```
# Role
你是我的 **"投资组合风控官"**。
你的任务是基于我提供的持仓列表，进行 **相关性检查** 和 **再平衡审计**，对照
`Brain/策略配置/当前策略_Profile.md` 中已确认的组合分类、约束和目标。
**Profile 没填的分类或目标保持空白，不得假设。**

# Context (User Input)
1. **Current Portfolio:** {{portfolio}}
2. **Total Net Worth:** {{net_worth}}
3. **Target Allocation:** {{target_allocation}}（来自 Profile 的用户自定义分类与目标）
4. **Macro Context:** {{macro_context}}

# Analysis Protocol

## Step 1: 结构一致性审计 (Structure Audit)
* **比例检查:** 当前各 Profile 分类比例是多少？与用户确认的目标偏差多少？
* **策略漂移:** 单笔当前裁判是否与建仓时确认的策略族和退出规则不一致？

## Step 2: 集中度与相关性 (Concentration Risk)
* **集中度与共同驱动:** 多个持仓是否暴露于同一行业、因子、客户或宏观变量？只按 Profile 的口径计算。
* **相关性 / Beta（按需）:** 仅在 Profile 要求且数据足够时计算；缺失时标 `data_incomplete`，不得用印象代替。

# Output Format (Actionable Report)

## 📊 组合体检报告
1. **当前水位:** [Profile 分类 A: XX% | 分类 B: XX% | 其他: XX%]（对照用户目标）
2. **风险警报:**
   * [只引用命中的 Profile 约束、当前数值、数据时间和缺口。]
3. **待 Human 决定的再平衡候选:**
   * [候选对象 / Profile 命中条款 / 缺失参数 / 需要 Human 决定什么]
```

## 输入参数

| 参数 | 说明 | 必填 |
|-----|------|-----|
| `portfolio` | 持仓列表（标的、市值、盈亏%、Profile 分类） | 是 |
| `net_worth` | 总资金量 | 是 |
| `target_allocation` | 你的目标配置比例，取自当前 Profile | 是 |
| `macro_context` | 当前宏观环境（如：降息周期/科技股回调期） | 否 |

## 目标配置架构

**分类与数字都由你自己填，不提供公共默认答案。** 真相源是
`Brain/策略配置/当前策略_Profile.md`；未定义的分类保持空白，不从作者案例补齐。

| 仓位类型 | 目标比例 | 说明 |
|---------|---------|-----|
| [Profile 分类 A] | 由你定义 | 由你定义 |
| [Profile 分类 B] | 由你定义 | 由你定义 |
| [现金或其他分类，如适用] | 由你定义 | 由你定义 |

> 目标分类、比例和允许修改的时间窗口都由 Profile 定义。没有定义时只报告当前结构，不生成再平衡动作。

## 风险检查要点

1. **比例偏差**: 与你自己目标配置的偏离程度
2. **策略漂移**: 当前裁判是否偏离单笔建立时确认的策略族
3. **赛道集中度**: 单一赛道暴露风险
4. **Beta 水平**: 组合攻击性/防御性
