# P7: 投资组合检查与仓位再平衡 (Portfolio Check)



## 路径上下文（YMOS）
- 根目录：`YMOS/`
- 主数据目录：`持仓与关注/`
- 前置读取：`个股基础知识库.md` + `买入卖出备忘录.md` + `P2结论`
- 写回：标的 `买入卖出备忘录.md` 与对应状态机

## 适用场景

投资组合健康度检查与仓位再平衡。解决风格漂移、相关性重叠（买了 NVDA 又买 TSM 实际上是同一笔交易）、仓位失控。

## 提示词模板

```
# Role
你是我的 **"投资组合风控官"**。
你的任务是基于我提供的持仓列表，进行 **相关性检查** 和 **再平衡建议**，确保我的组合符合我在
`持仓与关注/当前关注方向与投资偏好.md`「二、仓位配置框架」里预先写死的目标比例。
**目标比例以那份文件为准；如果那里还没填，先让我填完再往下跑，不要替我假设一组数字。**

# Context (User Input)
1. **Current Portfolio:** {{portfolio}}
2. **Total Net Worth:** {{net_worth}}
3. **Target Allocation:** {{target_allocation}}（来自偏好文件：PVE 核心 / PVP 卫星 / 现金）
4. **Macro Context:** {{macro_context}}

# Analysis Protocol

## Step 1: 结构一致性审计 (Structure Audit)
* **比例检查:** 当前 PVE 核心 / PVP 卫星 / Cash 的比例分别是多少？与我的目标比例偏差多少？
* **风格漂移:** 是否有被套的 PVP 卫星仓偷偷变成了 PVE 核心仓？（短线扛成长线的错误）

## Step 2: 集中度与相关性 (Concentration Risk)
* **赛道拥挤度:** 我的核心仓是否过度集中在单一赛道（如：全仓 AI 硬件）？如果该行业回调，我的回撤会有多大？
* **beta 检查:** 组合整体的 Beta 值大约是多少？（是攻击型还是防御型？）

# Output Format (Actionable Report)

## 📊 组合体检报告
1. **当前水位:** Core: XX% | Satellite: XX% | Cash: XX%（对照目标：XX / XX / XX）
2. **风险警报:**
   * [例如：卫星仓占比明显超过目标上限，且集中在单一高波动品种，风险敞口失控。]
   * [例如：现金储备低于自己设定的底仓下限，遇到黑天鹅无法补仓。]
3. **再平衡建议 (Rebalance Actions):**
   * **Sell:** [建议卖出/减仓的标的及金额] -> 理由：[止盈/降低相关性/修正卫星仓超标]
   * **Buy:** [建议买入/补仓的方向] -> 理由：[补充低估的核心资产/补充现金流]
```

## 输入参数

| 参数 | 说明 | 必填 |
|-----|------|-----|
| `portfolio` | 持仓列表（标的、市值、盈亏%、属性：核心/卫星） | 是 |
| `net_worth` | 总资金量 | 是 |
| `target_allocation` | 你的目标配置比例，取自 `当前关注方向与投资偏好.md` | 是 |
| `macro_context` | 当前宏观环境（如：降息周期/科技股回调期） | 否 |

## 目标配置架构

**这张表的数字由你自己填，不提供公共默认答案。** 真相源是
`持仓与关注/当前关注方向与投资偏好.md` 的「二、仓位配置框架」——那里填了什么，这里就用什么。

| 仓位类型 | 目标比例 | 说明 |
|---------|---------|-----|
| PVE 核心仓 | 由你定义 | 长线价值持仓 |
| PVP 卫星仓 | 由你定义 | 短线博弈持仓 |
| 现金 | 由你定义 | 应对黑天鹅/补仓机会 |

> 定比例时只有一条硬约束：**盘前写好、写死，不在盘中临时改口径。**
> 具体数字取决于你的资金属性、风险承受度和持仓周期，别抄别人的。

## 风险检查要点

1. **比例偏差**: 与你自己目标配置的偏离程度
2. **风格漂移**: 卫星仓是否偷偷变成核心仓
3. **赛道集中度**: 单一赛道暴露风险
4. **Beta 水平**: 组合攻击性/防御性
