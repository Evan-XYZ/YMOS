# P17: 核心资产判定 (Core Asset Audit) · v4 资产库版

> **作者内核扩展｜`disabled_by_default: true`** 这是作者真实使用过的策略模块，包含个人资产分类、评分与阈值。它不是 YMOS 公共公理；启用前必须映射到用户自己的 Strategy Profile，并保留 Human 最终确认。

> **v1（5-9 早盘）**：三问（核心资产 / 内在价值 / 份额捕获）—— 解决"是不是好"
> **v2（5-9 晚）**：升级到六问 + 两类机会标签 —— 解决"现在该不该买、买不买得到 alpha"
> **v3（5-10）**：把“资产等级”和“当前机会/买点”拆开 —— A 类资产不等于 A 类买点；A 类资产库用于长期动态监控，Q6 与综合裁决每日/每周刷新。
> **v4（5-12）**：新增 **Q7 股性 / 可持有性审计** —— 核心资产不能只看产业逻辑和估值，也要判断资金是否持续表达、K 线是否适合长期跟踪；P17 提前过滤“逻辑强但股性烂”的标的，P5 只负责临门买点审计。
> **V4（5-14 · 当前）**：新增 **Raise-and-Beat / 业绩上修势能** 作为 Q6/Q7 的交叉加权项 —— 同赛道多只都算核心资产时，持续 beat、持续上修指引、业绩兑现越来越好的公司，优先级应显著更高。
>
> **这套框架是从两类真实错误里长出来的**：
> ① **绕过判定就建仓**——沿着"产业链调研 → 直接买入"的路径走，中间没有一道"它到底算不算核心资产"的闸门。
> ② **把"已经涨了"误当成"已经晚了"**——一个标的涨了 30–50% 就不敢碰，却没算过终局空间还有几倍；也没有正面问过"它应该值多少"。
> v2 用 Q4–Q6（稀缺性 / 终局结构 / 势能传播阶段）+ 两类机会标签，把这两个缺口闭合。
>
> 本提示词独立可调用，可被 P1（初始调研）/ P5（买入决策）/ P7（组合健康检查）及用户自定义研究流程引用。

## 0. 最重要的拆分：资产等级 ≠ 当前买点

2026-05-10 校准：热门追踪产出的 “A/B” 先表示 **资产优先级**，不是直接买点。

- **A 类资产（Core / High-Odds Asset）**：长期核心资产或高赔率战略稀缺资产，值得自动建档、进入核心资产库、反复跟踪。它可能当前是“待回调”，也可能是“抢筹初期”。
- **B 类资产（Secondary / Tracking Asset）**：资产质量、稀缺性、终局空间弱于 A 类，但可能因估值 gap、事件催化、周期/主题发酵而值得价格跟踪。
- **当前机会标签**：由 Q6 + P9 gap + 价格事件决定，输出 `🚀 抢筹初期 / 👀 待回调 / 🟡 Conditional / 🔴 跳过`。

**2026-05-21 校准：核心资产只是 PVE 必要条件，不是充分条件。**

P17 通过只说明“它可能值得跟踪/研究/进入核心资产池”；真正的 `PVE_hold` 还需要 P9/P2/P5 同时确认：`合理估值 + 近期催化/势能 + raise and beat/确定性增强 + 股性可持有`。高估值但缺少确定性业绩支撑的核心候选，只能输出 `conditional_watch` 或 `PVP_trade`，不能伪装成 PVE。

所以输出必须同时给两行：
1. `资产等级：A类核心资产 / A类高赔率资产 / B类跟踪资产 / P2观察 / 跳过`
2. `当前机会标签：🚀 / 👀 / 🟡 / 🔴`
3. `潜在收益分级：A1/A2/A3/A4/A5/暂不分级 + 理由`




## 0.2 潜在收益分级（A1-A5）≠ 资产等级 ≠ 当前买点

新增口径：P17 收尾时必须给出 `潜在收益分级`，用于回答“这个机会如果成立，大概是哪一类收益空间”。它和资产等级、当前机会标签是三套不同维度：

分级的作用是**量级对齐**：不要用短线的期待去持有长线的仓位，也不要用长线的耐心去扛短线的结构。区间数值由你在 Strategy Profile 里按自己的市场、周期和资金成本定义，本表不提供默认值。

| 分级 | 空间量级 | 典型形态 |
|:---|:---|:---|
| A1 | 由 Profile 定义 | 常规短线势能 / 事件修复 |
| A2 | 由 Profile 定义 | 热门主线龙头 / 强 Beta 龙头弹性 |
| A3 | 由 Profile 定义 | 右侧初期的大级别势能，量价齐升、业绩快速增长、估值扩张同步发生 |
| A4 | 由 Profile 定义 | 长线大机会，核心资产 + 终局 TAM/份额捕获 + 估值重塑 |
| A5 | 由 Profile 定义 | 长线超级机会，平台级/基础设施级/产业周期重估 + 极高稀缺性 |

> 分级是对"机会形态"的归类，不是收益预测，更不是收益承诺。任何一档都可能归零。

使用纪律：
- A1/A2 可以是短线机会，不代表长期核心资产；A4/A5 可以是长线空间，不代表今天可以买。
- 分级必须由 P9 Base/Bull/Blue Sky、P17 Q5 终局空间、Q6 传播阶段、Q7 股性共同约束。
- 若证据不足，输出 `暂不分级`；不要为了显得有空间硬给 A3-A5。

## 0.5 统一五段式裁决契约（2026-05-12 新增）

P17/P9/P5 以后统一使用同一条分析链，避免“看对资产但落不到动作”：

```text
核心资产 → 应得价值 → 当前势能/业绩兑现 → 股性/资金认可 → 执行动作建议
```

五段分别回答：

| 段位 | 回答的问题 | 主责模块 | 输出要求 |
|---|---|---|---|
| 1. 核心资产 | 买谁 | P17 Q1/Q3/Q4 | 是否核心 / 稀缺 / 能捕获份额 |
| 2. 应得价值 | 为什么买、空间多大 | P9 + P17 Q2/Q5 | 应得估值区间、当前 gap、终局空间 |
| 2.5 潜在收益分级 | 这属于哪一档机会 | P9 + P17 Q5/Q6/Q7 | A1/A2/A3/A4/A5/暂不分级 + 成立条件 |
| 3. 当前势能/业绩兑现 | 为什么现在看 | P17 Q6 + 热门追踪/财报/事件 + Raise-and-Beat | 传播阶段、催化、是否早中期、业绩是否持续超预期/上修 |
| 4. 股性/资金认可 | 同赛道里优先买哪个 | P17 Q7 | 价格行为质量、资金表达、可持有性；财报/指引兑现后的持续反馈 |
| 5. 执行动作建议 | 下一步怎么处理 | P5/P12/Human | 仅给“建议进入买入链/Watchlist/等待/跳过”，不替 Human 下单 |

注意：第五段必须叫 **“执行动作建议”**，不是“执行动作”。P17 只能建议进入哪条链路；真实买入、加仓、卖出必须经过 P5/P12 与 Human 最终确认。

## 0.6 趋势资产三因子补充判定（2026-06-02 新增）

（这一段的框架来源建议单独沉淀在你自己的笔记库里，随实盘迭代。）

P17 的 Q1-Q5 解决“是不是核心资产 / 应该值多少 / 终局空间多大”；但是否值得进入真实交易仓或动态 Watchlist，还必须补一层趋势资产三因子：

```text
趋势资产 = 业绩右侧 + 产业右侧 + 股价右侧
```

三因子映射：

| 因子 | 在 P17 中的对应位置 | 审计问题 |
|---|---|---|
| 业绩因子 | Q6 + Raise-and-Beat | 近两期是否 solid？是否连续 beat / guide up / 订单收入利润兑现？ |
| 卡位因子 | Q1/Q3/Q4/Q5 | 是不是卡在当前市场正在定价的赛道势能上？是真卡位还是概念包装？ |
| K线因子 | Q7 | 趋势是否流畅？资金是否持续表达？弱市是否有承接？ |

输出纪律：

- 三因子全通过：可写 `A_trend / A_core_candidate`，建议进入真实深研或买入链前置。
- 只有卡位、没有业绩：写 `技术迁移观察 / B_tracking`，不得升级成趋势资产。
- 有业绩和卡位、但 K 线差：写 `逻辑硬但股性弱 / 资料观察`，不得伪装成舒服核心仓。
- K 线强但业绩和卡位未验证：写 `PVP / 事件交易`，不能用 PVE 逻辑长拿。

P17 收尾**必须输出**这一行（2026-06-11 起从"建议"升级为强制，所有深研报告/优先级排序/观察壳引用时不可省略）：

```text
趋势资产三因子：业绩因子 ?/40；卡位因子 ?/35；K线因子 ?/25；总分 ?/100；分层 A_trend / A_high_odds / B_tracking / P2_conditional / Block。
```

> 强制理由：三因子（业绩 + 卡位 + 股性）是 Human 买入决策的首屏语言；任何 P17 输出若缺这一行，下游 SOP（自动建档/策略分析）视为输出不完整，需补齐后再消费。

## 0.7 组级别 P17-lite：板块首发的先手裁决（2026-07-01 新增）

> 解决的问题：过去的路径是「板块异动 → 逐只 P9/P17 深研 → 才敢动」，等单票深研跑完，第一波往往已经走完（半导体硅材料组 6 月错过案例）。当多只个股同时指向一个细分板块时，**先动的是对板块代表权的判断，不是对某一只票的完整深研。**
>
> 触发来源：`SOP_Whats_Hot.md` 当期或近期报告中的「板块首发信号（SIS）」。SIS 只存在于可追溯报告中，不再维护第二份全局注册表。
>
> 定位：组级别 P17-lite 是 **先手裁决**，不是终判。它只回答「这条主线真不真、代表权是谁、现在处于哪一波、先手该不该动」，之后仍要对代表权逐只跑完整 P9/P17。它一次只放行 **1-2 只代表权（优先中军）**，不摊到全组；先手仓位受 P5 仓位纪律与 Q5 1/3 信念门约束。

调用时按五步输出「组级别 P17-lite 裁决卡」：

```text
组级别 P17-lite 裁决卡 — [细分板块名]

1. 主线确认度：确认主线 / 候选主线 / 题材脉冲
   - 依据：近3日入池只数、组内龙头5日强度、产业催化（硬=财报/订单/政策/产能，软=情绪/概念）、美股映射是否共振
   - 硬门槛：无明确产业催化的多股齐涨，最多「候选主线」，不给「确认主线」

2. 代表权分工（回答"这个方向第一组资金会买谁"）：
   - 中军 / 定价锚：[标的] — 大市值、高流动性、机构可配置、市场解释绕不开；通常是先手首选
   - 弹性龙头：[标的] — beta 最大、右侧加速抓手；股性强但波动大
   - Choke Point：[标的] — 设备/材料/耗材稀缺卡点、非对称收益；不是漂亮就先手，要看资金是否已表达
   - 低估值补涨：[标的]（可选）— 主线确认后的修复锚

3. 势能阶段：第一波抢筹初期 / 第一波加速中段 / 第一波加速后段 / 退潮
   - 判据：龙头「已涨幅 vs 终局粗估」比值、板块内跌幅池占比、连板/换手是否见顶、是否出现高位放量滞涨
   - 后段/退潮 = 追高必死区

4. 先手动作（不逐只深研）：
   - 初期/中段 且 代表权在击球区或贴近 → 先手代表权（优先中军）：快速 P5（含 Q5 信念测试）+ P12 → 观察仓/试错仓建仓
   - 加速后段 → 只在当期研究报告中登记代表权与待验证价格条件，等待下一次研究复核
   - 退潮/题材脉冲 → 只作板块温度计，不动
   - 无论哪种：把裁决写入当期报告并保留来源日期；Human 选中后才进入单标的决策文件

5. 驳回/降级信号：龙头短周期涨幅未达 Profile 设定的动能门槛且无加速、产业催化被证伪、板块跌幅池占比骤升、代表权高位放量滞涨 → 降为温度计或退潮

后续：先手放行的代表权，T+1~T+3 内补完整 P9/P17；组内其余成员按常规节奏逐只深研，不占用先手带宽。
```

纪律锚（务必守住）：
- **先手买的是"板块代表权"这个判断，不是"某只票已深研透"**；所以先手仓位天然是观察/试错级，等完整 P9/P17 与 1/3 信念门通过后才谈标准仓。
- **加速后段不用先手去弥补错过**：错过第一波是可接受的，追高不可接受；宁可等回踩或第二波。
- **一次只放行 1-2 只（优先中军）**：choke point / 弹性龙头除非资金已明确表达且在击球区，否则先登记不先手。

# Audit Task — 必须正面回答的七问

## Q1: 是不是核心资产 (Is It a Core Asset?)
* **生态位**：它在产业链的哪个生态位？（瓶颈缓解 / 价值放大 / 通用环节 / 替代品）
* **市场必要性**：它的商业模式是不是当前市场刚需？解决的是什么卡脖子问题或价值放大点？
  - 例：英特尔先进封装 = 缓解台积电先进封装产能瓶颈
  - 例：闪迪 = AI 服务器必需的存储部件
  - 例：某算力标的 = 主权级 GPU 算力里可见度最高的独立供应商
* **失去测试**：如果这家公司明天消失，行业是否真的受影响？影响程度多大？
* **软件 / 云服务补充**：若是 SaaS / DevOps / 云服务 / 网络安全，不能只按硬件瓶颈判断核心性；必须看客户锁定、API/数据/工作流嵌入深度、企业客户占比、订阅粘性、开发者生态。
* **裁决**：✅ 核心资产 / ⚠️ 边缘核心 / ❌ 非核心

## Q2: 内在价值是多少 (Intrinsic Value via Anchor Comparable)
*回答"应该值多少"，不是"贵不贵"。这一段可以借用 P9 的"对标参照系"产出。*

* **对标谁**：同生态位 / 同卡脖子点的可比公司是谁？给出 1-3 个对标
  - 例：英特尔先进封装 → 台积电美国厂的先进封装产能价值
  - 例：闪迪 → 在英伟达 BOM 中能捕获的存储份额 × 总 BOM 规模
  - 例：独立算力租赁商 → 对标云厂商 GPU 利润池的切分比例、同类租赁商的毛利率
* **应得估值区间**：基于对标的市值 / 利润池占比 / 业务模式相似度，回答它"应该值多少"——给区间不给精确数
* **当前 vs 应得**：当前市值是应得估值的 [溢价/折价] [百分比]
* **裁决**：💎 显著低估 / ⚖️ 合理定价 / 🔥 显著高估

## Q3: 能捕获什么份额 (Share Capture & Trajectory)
* **当前份额**：在产业链总利润池中能稳定捕获多少占比？给一个数字或区间
* **趋势**：份额是上升趋势 / 横盘 / 下降趋势？
* **根因**：份额变化的根因是什么？
  - 技术（独有专利 / 工艺领先）
  - 成本（规模优势 / 一体化）
  - 客户绑定（长约 / 切换成本）
  - 政策（出口管制 / 补贴）
* **可持续性**：上述根因在未来 1-3 年是否仍然成立？
* **裁决**：📈 份额上行 / ➡️ 稳定 / 📉 份额下行

## Q4: 稀缺性溢价 (Scarcity Premium · v2 新增)
* **稀缺度评级**：在赛道里这家公司多稀缺？
  - 🟢 极高稀缺：唯一供应 / 卡脖子点（形态：全球仅一家能量产的关键设备、被出口管制卡住的工艺环节、国产替代中唯一通过验证的供应商）
  - 🟡 中高稀缺：寡头之一（少数几家能供，但不是唯一）
  - ⚪ 同质化 / 可替代：无稀缺溢价
* **软件/云稀缺**：对 SaaS / 云服务，稀缺性不来自物理瓶颈，而来自高切换成本、客户数据锁定、开发者工作流嵌入、企业平台 bundling、NRR/扩张收入和生态插件。满足其中 3 项以上可给 🟡 中高稀缺；不能因“不是硬件”机械降为 ⚪。
* **稀缺度对估值的影响**（上浮幅度由 Profile 定义，本表只给方向）：
  - 极高稀缺 → 对 Q2 应得估值上浮（幅度自定）
  - 中高稀缺 → 小幅上浮（幅度自定）
  - 同质化 → 不调整或下调
* **裁决**：🟢 极高 / 🟡 中高 / ⚪ 一般

## Q5: 终局结构 / 牛市视角 (End-State Bull Case · v2 新增)
* **Beta 方向**：站在产业终局看，标的所在 beta 方向是上还是下？
* **宏观驱动校验**：列出这个终局判断所依赖的宏观驱动（由你在 Profile 里声明），逐条问"它今天是否仍然成立、什么证据会推翻它"。驱动本身是可证伪假设，不是前提。
* **3-5 年 price-in 测试**：
  - 如果未来 3-5 年这家公司收入翻 3-5 倍，对应市值是多少？
  - 这个市值相比当前市值的 gap 是多少？
* **2026-05-13 口径校准：终局市值不是现有收入倍数外推**
  - 不要只用上一年或当前收入乘一个估值倍数来定义 Bull case；至少从当前年份和最新确定性指引起算。
  - Bear/Base 可用当前年收入/利润 + 保守倍数；Bull 应看 2028+ 收入/利润、产业 TAM、可捕获份额、稀缺性/议价权和叙事切换。
  - 必须问：公司在产业链里能收哪一层“税”？例如 HBM TAM 中公司可捕获多少收入，DRAM/存储弹性是否让估值从周期股切换成成长股。
  - Bull case 要有想象力；Blue Sky 可单列，但要明确触发条件，不把 Sky 当当前买点。
* **校准动作**：检查这次估值用的是不是和当前市场阶段一致的心智——用熊市假设去 price 牛市资产，和用牛市假设去 price 熊市资产，是同一类错误。写明你这次采用了哪种假设及理由。
* **资产类型校准**：
  - 硬件/存储/半导体：必须区分结构性重估 vs 周期高点。
  - SaaS/云服务：用 ARR/FCF CAGR + 高毛利可持续性判断 3-5 年合理倍数，不能默认 <3x。
  - 商业航天/深科技：用任务节点成功率、RPO/backlog 转收入、现金 runway 和稀释风险折现终局空间。
  - 服务器/交付链：用 backlog 转收入 + margin 稳定性校准，不因 PS 低就自动给高分。
* **裁决**（分档阈值由 Profile 定义，本表只给排序方向）：
  - 🚀 终局空间显著大于当前 → 满足牛市视角准入
  - 📈 终局空间中等 → 满足准入，但赔率已下降
  - ⚖️ 终局空间偏小 → 已 priced in 较多
  - 📉 终局空间小于当前市值（透支）→ 不满足买入链准入

> 裁决只描述"是否满足你自己定义的准入条件"，不是买卖建议；动作仍由买卖决策台与 Human 决定。

## Q6: 势能传播阶段 (Momentum Diffusion Stage · v2 新增)
* **当前价格反映了势能传播的哪个阶段？**
  - 🌱 **萌芽 / 早期**：财报刚开始验证，涨幅小或“剩余空间/已涨幅”仍很高，机构覆盖不充分 → 右侧初期
  - 🌿 **加速 / 中期**：产业逻辑被主流接受，业绩兑现与股价同步扩散，仍有空间但赔率下降
  - 🍂 **成熟 / 末期**：大部分乐观预期已 price in，P9 赔率下降，需要回调/新催化
  - 🧊 **衰退 / 失效**：主逻辑转弱，或业绩兑现赶不上估值，需移出买入链/降级
* **关键判定原则**：早期判定**不看绝对涨幅**，看「剩余空间 / 已涨幅」比值
  - 例：某标的从 $40 涨到 $60（已涨 50%），但终局空间 $200，比值 7:1 → 仍属早期
  - 例：某 AI 概念股从 $10 涨到 $30（已涨 200%），但终局空间 $35，比值 0.25:1 → 末期
* **传播信号检查**：
  - 机构覆盖：研报数量 / 主流财经媒体提及频次（早期 < 中期 < 末期）
  - 散户认知：reddit/雪球 提及频次（早期低，末期高）
  - 财报兑现进度：本轮 thesis 已兑现几个季度？（0-1 季 = 早期，2-3 季 = 中期，4+ 季 = 末期）
* **Raise-and-Beat / 业绩上修势能（V4 加权项）**：
  - 最近 2-4 个季度是否连续收入 / 利润 / 毛利率 / 订单 / RPO/backlog beat？
  - 管理层指引、券商一致预期、订单/产能口径是否持续上修，而不是一次性利好？
  - Beat 后市场是否继续上修未来 1-2 年预期，还是只当成短期交易？
  - 若同赛道多只标的 Q1-Q5 都过线，**优先选择“业绩越来越好 + 预期持续上修”的公司**；这通常说明它站在正确的经营势能和资金势能上。
  - 反向扣分：只 beat 一次但指引保守、收入增长靠一次性订单、利润率被价格战侵蚀、或每次利好后高开低走。
* **裁决**：🌱 萌芽/早期 / 🌿 加速/中期 / 🍂 成熟/末期 / 🧊 衰退/失效

## Q7: 股性 / 可持有性审计 (Price Action Quality · v4 新增)
*定位：Q7 不是判断“今天能不能买”，而是判断这个资产的价格行为是否支持它进入核心资产池 / 重点 Watchlist。P17 看长期可跟踪性，P5 再看当前买点。*

* **相对强度（RS）**：过去 20/60/120/250 个交易日，相对指数、行业、同主线核心标的是领涨、跟涨、滞涨还是补跌？
* **上涨捕获（Upside Capture）**：行业 / 主线走强时，它是主动领涨、流畅跟涨，还是板块涨它不涨？上涨是否有连续性？
* **下跌抵抗（Downside Capture）**：指数 / 行业回撤时，它是否明显抗跌？下跌是缩量承接，还是放量出逃 / 杀 beta？
* **回撤修复速度（Recovery Speed）**：近 6-12 个月主要回撤后，通常多少交易日修复？跌破 MA20/MA60 后是否能快速站回？
* **趋势流畅度（Trend Smoothness）**：均线结构是否健康？是否经常出现长上影、冲高回落、突破失败、放量大阴线、跳空低开？
* **量价健康度（Volume-Price Health）**：上涨是否温和放量、回调是否缩量？是否经常放量大阴线或无量阴跌？
* **事件反馈（Event Reaction）**：财报、订单、政策、行业催化后，价格反馈是正向持续，还是高开低走？利空后是否能快速修复？尤其要看 beat/raise 后是否形成“预期上修 → 股价确认 → 再上修”的正循环。
* **股性类型裁决**：
  - 🟢 核心资产型好股性：强逻辑 + 强资金表达，适合核心资产池持续跟踪。
  - 🟡 趋势可交易型股性：趋势 / 弹性不错，但仍需 P9/P5 约束买点。
  - 🟠 逻辑强但股性弱：只允许低吸 / 高赔率区审计，不追右侧，不默认重仓。
  - 🔵 脉冲交易型股性：事件或题材驱动强，但不适合伪装成长期核心资产。
  - 🔴 恶劣股性：骗炮、阴跌、修复慢、持有体验差；原则上剔出核心池。
* **评分建议（100 分）**：相对强度 20 / 上涨捕获 15 / 下跌抵抗 15 / 回撤修复 10 / 趋势流畅 10 / 量价健康 10 / 事件反馈 10 / **Raise-and-Beat 业绩上修势能 10**。
  - 85-100：优秀股性，可核心跟踪；70-84：良好股性，可 Watchlist；55-69：中性，只观察；40-54：弱股性，仅事件交易；<40：恶劣股性，剔除核心池。
  - 同赛道横向二选一时，若总分接近，优先选择 Raise-and-Beat 分明显更高的标的；若连续 miss / guide down，即使价格短期强，也要降低 Q7 可信度。
* **硬纪律**：若 Q7 连续低于 C / 55 分，即使 Q1-Q5 逻辑强，也不得直接进入“舒服长拿核心仓”；只能降级为“逻辑强但股性弱观察池”，等待股性修复或更高赔率补偿。

## 反向复盘清单（一次性历史校准）

**建议第一次用 P17 时，先别拿它看新标的，而是拿它复盘自己过去的账。**

挑 3–5 个你**真实错过或做错**的案例——最好覆盖这几类：

- 看对了逻辑但没买（想知道当时缺哪一问）
- 买了但拿不住（多半是 Q7 股性 / 可持有性没过）
- 涨了一截就不敢碰，结果后面还有几倍（Q5 终局空间没算）
- 逻辑很好但一直不涨（Q6 势能传播阶段判错）

对每个案例回到**当时**的信息状态跑一遍七问，看框架当时会不会给出正确信号。
跑完你会很清楚：这套问题里哪几问对你最有效，哪几问需要按你自己的风格调权重。

> 校准完再往前用。**没被自己的历史验证过的框架，不值得拿真金白银去试。**
