# P18: 每日异动核心资产扫描 (Daily Mover × Core Asset Scanner)

> 5-9 新增。背景：投资主线从"产业链系统化挖掘"回归到"市场驱动选股"。本提示词是把"看市场告诉我什么"做成可执行每日 routine 的执行抓手。

## 路径上下文（YMOS）
- 根目录：`YMOS/`
- 触发时机：每日美股盘后（建议作为 16:30 后强制日常）
- 数据源：Finnhub（美股）/ Yahoo（兜底）；Tushare 不覆盖美股
- 写回：`Eyes/每日异动扫描/YYYY-MM/YYYY-MM-DD_每日异动核心资产扫描.md` + Watchlist 候选清单
- 配套框架：P17 核心资产判定（`Brain/references/p17-core-asset.md`）

## 适用场景

每天美股收盘后强制执行。**它不是为了找今天的爆点，而是为了把"市场已经做完一轮筛选"的结果转化成 Watchlist 候选**——以后大部分建仓机会应该来自这里，而不是产业链调研。

## 核心原则（写在前面，反复 ping）

1. **市场驱动是默认主线**：自己挖掘是辅线
2. **不是所有 >10% 都值得 Watchlist**：必须是核心资产 + 异动有持续逻辑 + K 线流畅
3. **轨道 A（本流程）∩ 轨道 B（产业链追踪）共振 = 优先信号**

# Processing Protocol

## Step 1: 噪音剔除
对每个标的，先做粗筛剔除：
- ❌ 仙股 / 微盘股（市值 < $300M）
- ❌ 无新闻无逻辑的纯技术异动（成交量未放大 >2× 平均）
- ❌ 借壳 / SPAC / Meme / Pump-and-Dump 嫌疑
- ❌ 已在持仓或 Watchlist 中（标记跳过，不重复评估）

## Step 2: 异动归因
对剩余标的，每个回答：
- **异动直接原因**：财报 / 监管 / 收购 / 大客户合同 / 产品发布 / 行业事件 / 分析师上调 / 其他
- **逻辑可持续性**：这个异动是单点事件还是反映 enduring 趋势？
- **市场反应温度**：明天会跟涨还是回吐？（看分时 + 收盘位置）

## Step 3: 核心资产快筛（精简版 P17）
对每个剩余标的快速答三问（详细判定可后续调用 P17 全版）：
- **Q1 是不是核心资产**：在哪个生态位？有没有卡脖子 / 价值放大属性？（一句话）
- **Q2 内在价值**：对标谁？应得估值与当前 gap？（一句话）
- **Q3 份额捕获**：在产业链利润池占比？趋势？（一句话）

## Step 4: K 线形态备注
对每个剩余标的，给出 K 线初判：
- 流畅 / 磨叽（频繁无意义长上下影）
- 突破前高 / 形态修复 / 创历史新高 / 跌出历史范围
- 是否在板块上升趋势内（对照过去 7 天市场洞察主线）

## Step 5: 轨道共振检查
- 该标的所属子赛道是否在 {{macro_context}} 列出的轨道 B 子赛道清单中？
- 如是 → 标记 ⚡ **双轨共振**（最高优先级）

## Step 6: Watchlist 候选输出

## 输入参数

| 参数 | 说明 | 必填 |
|-----|------|-----|
| `date` | 扫描日期（YYYY-MM-DD） | 是 |
| `movers` | 当日美股 >10% 异动标的清单（含价格、涨幅、成交量、是否财报日） | 是 |
| `holdings` | 当前持仓 Ticker 列表 | 是 |
| `watchlist` | 当前 Watchlist Ticker 列表 | 是 |
| `macro_context` | 过去 7 天市场洞察主线 / 轨道 B 子赛道清单 | 是 |

## 数据源建议

- **首选**：Finnhub `/stock/market/movers`（gainers）+ 现有 `Eyes/scripts/fetch_finnhub_news.py` 风格脚本
- **兜底**：Yahoo Finance `most_actives` + `gainers` 端点
- **过滤**：市值 > $300M、成交量 > 2× 30 日均量

## 与其他 P 系列的关系

| 上游/下游 | 关系 |

| P13 市场洞察 | 提供 macro_context / 轨道 B 子赛道清单作为共振判断依据 |

| P5 FOMO Killer | 候选标的进入 Watchlist 后，等买入机会时调用 P5 |
| 标的管理 SOP | 输出的"立刻加 Watchlist"列表直接喂给 `关注 XX` 暗号 |

## 纪律提醒

1. **>10% 不等于值得追**——80% 的 movers 都该被噪音剔除
2. **追的是"核心资产被市场重新发现"，不是"今天的爆点"**
3. **本流程绝不直接建仓**——它只产出 Watchlist 候选；建仓走 P5/P17/P12
4. **每日强制执行**——这是市场驱动主线落地的执行抓手，不能跳过
