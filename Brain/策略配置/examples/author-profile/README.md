# 作者策略结构参考（默认禁用）

> `disabled_by_default: true`

这个目录解释“一套个人策略如何映射成 YMOS 内核”，并提供默认关闭的模块清单。它不提供公共默认参数，也不构成任何策略建议。

作者的自用系统曾组合使用：基本面/景气证据、估值与赔率判断、价格行为验证、组合风险约束和 Human 门禁。这套研究与执行链在真实资金上被完整跑过一个有效周期。这是一段真实历史，不是经独立审计的归因实验：它不能证明 P17/P18 具有独立因果效力，也不代表未来结果。

可以参考的是结构：

1. 每种入场理由都有对应的认错方式。
2. 仓位、期限与论点周期必须互相匹配。
3. 盘前形成判断，盘中只按已写条件执行。
4. 每次偏离都会留下证据，重复偏离才可能触发内核修改。

仓库开放的作者扩展包括：

- P17 核心资产判定与 P18 每日异动扫描。
- P9+P17 单标的专项调研。
- What's Hot、美股热门追踪与 Watchlist 自动建档。
- 核心资产动态判定、A 股回踩提醒及对应扫描脚本。

这些模块完整保留，是为了展示一个内核怎样从研究经验继续演化；它们不参与新用户的最小运行链，也不自动加入定时任务。

不能照抄的是：

- 具体市场、标的与关注方向。
- 仓位、止损、周期和筛选阈值。
- 模块里的评分权重、门槛、市场映射和调度节奏。
- 作者当前使用的任何策略参数。

## 启用流程

1. 从 `_模板_策略_Profile.md` 建立自己的 Profile。
2. 查看 `module-manifest.example.json`，只选择自己理解并具备数据条件的模块。
3. 将每个模块标记为 `profile` 或 `optional`；不要标记为公共 `invariant`。
4. 把模块里的数值和资产标签改成自己的规则，未确认字段保持关闭。
5. 先手动运行，验证空数据、失败降级、重复执行和 Human 写回边界。
6. 最后才配置自己的时间表；不要复制作者真实调度。

推荐依赖链：

```text
价格/事件驱动
  → P18 或热门追踪（只生成候选）
  → P17 / P9（研究与分类）
  → P5 / P12（动作前审计）
  → Human
  → 通用买卖决策台留痕
```

用户应通过诊断和自己的历史证据填写 Profile。作者扩展可以被删除或替换，删除后不影响 YMOS 最小闭环。
