# 初始调研 SOP

> 暗号：`调研一下 [ticker]`

## 定位

为用户指定对象建立可追溯的事实底座、观察指标与当前环境识别。初始调研不替用户选择策略，不自动进入 Watchlist 或持仓。

## 前置

1. 默认进入**事实调研模式**：可选读取 `持仓与关注/当前关注方向与投资偏好.md` 了解最近为何关注，但不读取 Strategy Profile，也不要求先配置内核。
2. 只有用户明确要求“按我的策略评估”或把研究继续路由成动作判断时，才进入**策略适配模式**并读取 `Brain/策略配置/当前策略_Profile.md`；缺失或为 `draft` 时仍完成事实调研，策略适配部分返回 `kernel_not_ready`。
3. 解析标识符、市场、币种与正式披露入口。
4. 确认写入目标；目录不存在时只在 Human 已要求建档的范围内创建。Human 尚未要求建档时，写入 `Eyes/投资雷达/YYYY-MM/YYYY-MM-DD_[ticker]_有题调研.md`，不得自动创建 Watchlist/持仓目录。

## 执行

### P1 基石档案

读取 `Brain/references/p1-genesis.md`，收集治理、商业模式、客户与供应商、竞争、财务、资本需求、风险和关键指标。所有关键事实带来源、口径和时间；搜索不到则标记未知。

### P4 观察雷达

读取 `Brain/references/p4-radar.md`，将公司事实、待验证问题和已有论点拆为公司、竞争、价值链、外部环境与事件观察点。事实模式只形成“盯什么、为什么”，不发明阈值；策略适配模式的阈值才来自 Profile 或 Human。

### P2 环境识别

事实模式只记录可观察的价格阶段和环境证据，不套用个人裁判。只有进入策略适配模式且 Profile 可用时，才读取 `Brain/references/p2-phase-check.md`，输出适配、冲突、待验证和可证伪信号。

### P9（按需）

仅在用户要求估值且数据足够时运行 `p9-valuation.md`。事实模式可以整理公开估值事实与缺口；需要使用个人回报要求、期限或分级阈值时必须进入策略适配模式。假设与情景必须显式，不把模型结果当作事实。

## 写回

- 已有或经 Human 批准新建标的档案时，更新单标的 `个股基础知识库.md` 的 P1/P4 事实区块；只有策略适配模式才更新 Profile 已启用的 P2/P9 区块。
- ad-hoc 研究写入 `Eyes/投资雷达/YYYY-MM/YYYY-MM-DD_[ticker]_有题调研.md`，只保存事实、来源、未知与后续验证项。
- 追加调研日期、来源清单、关注文件版本（若读取）、Profile 版本（仅策略适配模式）与仍缺资料。
- 只在 Portfolio State 角色权限内更新状态机摘要；不得改变身份。

## 成功判定

- 事实、解释、假设和未知已分开；
- 每个关键判断能追溯来源；
- 观察指标和可证伪信号明确；
- 未写入作者行业偏好或公共默认参数；
- 无 Profile 时仍完成了事实底座，没有把轻量关注文件当成动作规则；
- 下一步是研究建议，不是交易指令。
