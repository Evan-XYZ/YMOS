# 初始调研 SOP

> 暗号：`调研一下 [ticker]`

## 定位

为用户指定对象建立可追溯的事实底座、观察指标与当前环境识别。初始调研不替用户选择策略，不自动进入 Watchlist 或持仓。

## 前置

1. 读取 `Brain/策略配置/当前策略_Profile.md`；不存在、为 `draft` 或 scope 为空时，只允许建立 ad-hoc 事实研究。`draft` 不阻塞事实调研，但不能产生策略适配、动作级结论或身份变更。
2. 解析标识符、市场、币种与正式披露入口。
3. 确认写入目标；目录不存在时只在 Human 已要求建档的范围内创建。Human 尚未要求建档时，写入 `Eyes/投资雷达/YYYY-MM/YYYY-MM-DD_[ticker]_有题调研.md`，不得自动创建 Watchlist/持仓目录。

## 执行

### P1 基石档案

读取 `Brain/references/p1-genesis.md`，收集治理、商业模式、客户与供应商、竞争、财务、资本需求、风险和关键指标。所有关键事实带来源、口径和时间；搜索不到则标记未知。

### P4 观察雷达

读取 `Brain/references/p4-radar.md`，将长期论点拆为公司、竞争、价值链、外部环境与事件观察点。阈值来自 Profile 或 Human，不使用示例值。

### P2 环境识别

读取 `Brain/references/p2-phase-check.md`，对照 Profile 输出适配、冲突、待验证和可证伪信号。

### P9（按需）

仅在用户要求估值且数据足够时运行 `p9-valuation.md`。假设与情景必须显式，不把模型结果当作事实。

## 写回

- 已有或经 Human 批准新建标的档案时，更新单标的 `个股基础知识库.md` 的 P1/P4，以及 Profile 已启用的 P2/P9 区块。
- ad-hoc 研究写入 `Eyes/投资雷达/YYYY-MM/YYYY-MM-DD_[ticker]_有题调研.md`，只保存事实、来源、未知与后续验证项。
- 追加调研日期、来源清单、Profile 版本与仍缺资料。
- 只在 Portfolio State 角色权限内更新状态机摘要；不得改变身份。

## 成功判定

- 事实、解释、假设和未知已分开；
- 每个关键判断能追溯来源；
- 观察指标和可证伪信号明确；
- 未写入作者行业偏好或公共默认参数；
- 下一步是研究建议，不是交易指令。
