# 策略分析｜脱敏示例

> **合成场景：** 用户要求评估虚构标的“云桥互连（DEMO-A）”。
> 为展示完整效果，本例假设用户已经确认一份示例 Profile；其中没有作者仓位、账户金额或真实交易记录，规则也不会写入任何运行文件。

## 1. 本次任务

| 项目 | 内容 |
|:---|:---|
| 触发暗号 | “我想买 DEMO-A” |
| 标的身份 | Watchlist，尚未建仓 |
| 上游来源 | 投资雷达发现网络瓶颈主题连续强化 |
| 本次目标 | 判断证据是否足以进入“建仓准备”，不是预测明天涨跌 |
| 最终权限 | Human 决定；Agent 不下单、不伪造成交 |

## 2. 输入新鲜度

| 输入 | 状态 | 截止时间 | 是否可用于动作判断 |
|:---|:---|:---|:---|
| 市场洞察 | ✅ | 示例日 08:00 | 可用于环境背景 |
| 投资雷达 | ✅ | 示例日 08:30 | 可用于候选来源 |
| 初始调研 | ✅ | 示例日 09:10 | 可用于论点事实 |

| 账户快照 | ⚠️ 缺失 | — | **不能计算具体仓位** |

## 3. 从 Profile 读取的判断方式

本例只展示结构，不给公共数值：

- **主要机会类型：** 产业瓶颈解除前的供给控制权。
- **入场证据：** 客户验证、量产节奏、收入质量至少形成相互独立的证据组合。
- **失效裁判：** 客户验证失败、量产持续延期，或收入增长无法转成现金流。
- **仓位语言：** 趋势与证据同向时使用正常仓；环境震荡或证据不完整时减半；无法计算账户风险时不输出手数。
- **Human 门禁：** 建仓准备、真实成交和规则变更都需人工确认。
- **本次启用模块：** 初始事实、冲动审计、组合约束、最终纪律裁判。

## 4. 原始论点复现

### 一句话论点

如果 AI 集群继续扩大，网络互连会成为系统吞吐瓶颈；DEMO-A 若能把客户验证转成量产订单，可能获得高于行业平均的收入弹性。

### 论点成立需要同时满足

1. 客户验证不是一次性试样，而是进入明确量产阶段。
2. 出货增长没有被快速降价和良率成本抵消。
3. 公司扩产与现金流承受能力匹配。
4. 竞争对手没有在同一代产品上明显缩短差距。

### 可观察的失效信号

| 信号 | 如何观察 | 出现后的默认动作 |
|:---|:---|:---|
| 量产时间连续推迟 | 公告、财报、客户口径交叉验证 | 暂停动作并重审 |
| 收入增长但毛利持续恶化 | 连续财务数据 | 降低论点等级 |
| 应收和库存快于收入增长 | 资产负债表与现金流 | 检查是否透支需求 |
| 客户切换到替代方案 | 客户 / 供应链信息 | 进入退出裁判 |

## 5. 模块化审计

### 事实层：候选为什么进入系统

- 网络瓶颈主题已连续多期出现，不是单日 headline。
- DEMO-A 完成了一个客户验证节点，但量产规模尚未得到第二来源确认。
- 价格相对强度改善，只能证明关注度提高，不能证明收入兑现。

**结果：** 值得研究，尚不足以直接产生动作。

### 冲动审计：现在想买的真正原因

| 问题 | 本次回答 |
|:---|:---|
| 如果今天价格没有上涨，还会不会想研究？ | 会，主题连续性和客户验证仍存在 |
| 是在买已确认事实，还是害怕错过？ | 两者都有；价格走强放大了紧迫感 |
| 有无把“进入验证”偷换成“必然量产”？ | 有这个风险 |
| 能否写出下一条反证？ | 可以：量产延期或毛利兑现失败 |

**结果：** 不是纯 FOMO，但紧迫感正在推动用户跳过量产证据。

### 组合约束：是否具备计算条件

账户快照缺失，系统无法判断：

- 当前同主题暴露是否已经过高；
- 资金期限能否覆盖论点兑现周期；
- 正常仓和减半仓对应多少金额或手数。

**结果：** data_incomplete。不得输出“买几手”或具体仓位。

### 最终纪律裁判

| 门禁 | 状态 | 说明 |
|:---|:---|:---|
| 论点可复述 | ✅ | 已写清瓶颈、客户验证和兑现路径 |
| 失效信号可观察 | ✅ | 延期、毛利、库存与客户切换可核查 |
| 入场证据完整 | ❌ | 缺量产规模与收入质量第二证据 |
| 风险可计算 | ❌ | 缺账户快照 |
| Human 已确认 | ⏳ | 尚未进入建仓准备 |

## 6. 决策结论

### 当前裁决：不进入建仓准备

这不是“看空 DEMO-A”，也不是预测价格会下跌。系统拒绝的是：在量产证据和账户风险都不完整时，把研究价值直接翻译成交易动作。

**允许继续：**

- 保持 Watchlist 身份；
- 补充量产规模、毛利和现金流验证；
- 更新账户快照后重新计算风险；
- 由 Human 决定是否重新触发买入审计。

**当前禁止：**

- 因为价格上涨而降低证据门槛；
- 用示例仓位或作者参数填补账户缺口；
- 创建“已成交”或“已执行”记录；
- 把本次单标的结论自动升级为长期策略规则。

## 7. 下一步最小动作

| 优先级 | 下一步 | 完成标准 |
|:---|:---|:---|
| 1 | 补量产证据 | 至少两个独立来源能说明客户、规模和时间 |
| 2 | 补收入质量 | 毛利、库存、应收与现金流方向不冲突 |
| 3 | 刷新账户快照 | 能计算同主题暴露和资金期限 |
| 4 | Human 复核 | 用户确认原论点、失效信号和风险边界 |

建议暗号：

- **调研一下 DEMO-A 的量产与收入质量**
- **刷新一下持仓体检**
- **证据补齐后，重新跑“我想买 DEMO-A”**
