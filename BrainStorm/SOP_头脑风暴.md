# SOP：头脑风暴

> 模块：BrainStorm/（思考沉淀层）
> 目标：把口语化的碎片想法 → 结构化总结 → 长期原则，并在合适的时候联动 YMOS 投研链路。
> 相关脚本：`BrainStorm/scripts/brainstorm_memory.py`

---

## 暗号速查

| 说这句话 | AI 做什么 |
|:---|:---|
| **「开始今天的头脑风暴」** | 加载 `MEMORY.md` + `状态机/STATUS.md` + 最近 7 天 Insight → 进入对话 |
| **「整理一下今天说的」** | 本次对话 → 结构化总结 → 写入 Raw_Thoughts + Summarized_Insights |
| **「把这个感悟沉淀下来」** | 单条认知 → 追加到 `MEMORY.md` 或 `投资感悟归档/短期灵感/` |
| **「复盘一下这段时间」** | 扫描最近 Insight → 提炼重复出现的模式 → 建议升级为框架 |
| **「给我下一步行动指南」** | 结合 STATUS + 最近 Insight → 输出可执行清单 |

## 标准流程（三步）

### Step 1：加载上下文（AI 自动执行）

```bash
python3 BrainStorm/scripts/brainstorm_memory.py --preview
```

加载内容：
1. `MEMORY.md` — 长期有效的认知与已验证原则
2. `状态机/STATUS.md` — 当前阶段在哪、最近焦点是什么
3. 最近 7 天 `Summarized_Insights/` — 近期思考脉络

**为什么必须先加载**：不加载上下文的头脑风暴，等于每天从零开始。
AI 会给出一堆你三个月前就否定过的建议，而你自己也想不起来当时为什么否定。

> 若同时在用 `持仓与关注/当前关注方向与投资偏好.md`，也应一并读取——
> 那是你的投资宪法，讨论任何具体标的前都该先对齐它。

### Step 2：自由输入（用户主导）

- 口语化说出想法、困惑、感悟、灵光一现
- 语音转文字直接说，不需要整理格式
- **越原始越真实越好**

**AI 在这一步的职责是追问，不是附和**：

- "为什么这样想？有没有实盘例子？"
- "如果反过来呢？什么情况下这个判断会失效？"
- "这和你上个月说的 X 是不是矛盾？"

最后一问尤其重要。**AI 有历史上下文，你没有——这是它最大的价值，不要浪费在夸你上。**

### Step 3：整理归档

说「整理一下今天说的」，AI 执行：

```
读取本次完整对话
  ↓
写入 每日头脑风暴/Raw_Thoughts/YYYY-MM/YYYY-MM-DD.md   （原始，追加）
  ↓
生成结构化总结（300-500 字）
写入 Summarized_Insights/YYYY-MM/YYYY-MM-DD_Insight.md
  ↓
判断：有没有值得写入 MEMORY.md 的新认知？
  → 有 → 提示用户确认后追加      ← 不要静默写
  → 无 → 跳过
  ↓
判断：要不要联动 YMOS？
  → 对某标的有新判断  → 提示「要不要跑 深研一下 XX？」
  → 对板块有新洞察    → 提示「要不要跑 市场洞察 / P13 确认？」
  → 是纪律类教训      → 提示「要不要回写到 当前关注方向与投资偏好.md 的红线清单？」
```

## Raw_Thoughts 记录标准

> Raw_Thoughts 要**偏详细**，服务于未来复盘与复现，不能只剩抽象结论。

### 每个关键节点至少要有

1. **时间戳** — 至少到分钟
2. **原始观点** — 保留当时的具体说法，可压缩但不能只剩一句结论
3. **上下文** — 这条观点在解决什么问题、对应哪个阶段
4. **为什么重要** — 影响的是仓位、纪律、还是研究方向
5. **可执行检查项** — 后续复现时能直接用的触发条件

### 禁止写法

- ❌ 只写"今天有个新想法，待跟进"
- ❌ 只有抽象标签，没有具体细节或例子
- ❌ 无时间、无上下文，事后无法回放当时的决策过程

### 推荐写法

- ✅ **观点 + 原因 + 例子 + 后续触发条件** 四联结构
- ✅ 关键原话片段（1-2 句）+ 归纳解释
- ✅ 同日多轮对话做成合并版时间线

## 存储规则

| 内容类型 | 路径 | 命名 |
|:---|:---|:---|
| 原始想法 | `每日头脑风暴/Raw_Thoughts/YYYY-MM/` | `YYYY-MM-DD.md`（同日追加） |
| AI 整理总结 | `Summarized_Insights/YYYY-MM/` | `YYYY-MM-DD_Insight.md` |
| 单条投资感悟 | `投资感悟归档/短期灵感/` | `YYYY-MM-DD_主题.md` |
| 成体系的方法论 | `投资感悟归档/长期框架/` | `框架名.md` |
| 可勾选操作清单 | `投资感悟归档/执行清单/` | `场景名.md` |
| 长期记忆 | `MEMORY.md` | 追加，不新建 |
| 阶段状态快照 | `状态机/YYYY-MM/` | `YYYY-MM-DD.md` |

## 升级判据：什么时候该往上一层走

| 从 | 到 | 判据 |
|:---|:---|:---|
| Raw Thought | Insight | 当天聊出了明确结论或行动项 |
| Insight | 短期灵感 | 这条感悟有具体交易触发，且你想让它以后被翻出来 |
| 短期灵感 | 长期框架 | **同类感悟出现 ≥3 次**——说明这不是偶然，是模式 |
| 长期框架 | 执行清单 | 框架已经稳定到能拆成可勾选的动作 |
| 执行清单 | **投资偏好 / 红线清单** | 你愿意让系统在下次出手时**用它拦你** |

> 最后一跳是整个 BrainStorm 存在的意义。
> **一条感悟如果永远不进入偏好文件和红线清单，它就永远不会改变你的行为。**

---

## 纪律

- **不静默写 MEMORY.md**：AI 可以起草，必须用户确认后才写。
- **Raw 不修饰**：原始记录就该保留当时的口气和混乱，修饰过的记录是给别人看的，不是给未来的自己看的。
- **不为了写而写**：没想法的那天，写一句"今天做了什么交易，为什么"就够了。
- **定期清理**：Insight 层可以留，Raw 层三个月前的可以只留标题——但**别删**，硬盘比记忆便宜。
