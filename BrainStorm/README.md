# BrainStorm — 投资思考沉淀区

> 你每天冒出来的想法、复盘时的感悟、想不通的困惑，都在这里落地。
> **三层架构：原始输入 → AI 整理 → 长期归档。按日保存，按月归档。**

---

## 为什么 YMOS 需要这一层

前面几个模块处理的都是**结构化**的东西：市场数据、状态机、估值、门禁。
但投资里真正决定长期水位的，往往是些**没法结构化**的东西：

- "我为什么每次都在最低点割"
- "这次赚钱到底是因为方法对，还是运气好"
- "我好像总是在同一类标的上犯同一个错"

这些想法有个共同特点：**冒出来的时候很清晰，三天后就忘了，三个月后又原样犯一遍。**

BrainStorm 的作用就是接住它们，并且让它们**能被翻出来**。

> 一个具体的判断标准：**如果你今年犯的错，和去年犯的错是同一个，那说明你缺的不是方法，是这一层。**

## 三层架构

```
Layer 1  原始输入          你说什么就记什么，不整理、不修饰
   ↓     每日头脑风暴/Raw_Thoughts/YYYY-MM/YYYY-MM-DD.md
   
Layer 2  AI 整理           压缩成关键洞察 + 下一步行动 + 待深入问题
   ↓     Summarized_Insights/YYYY-MM/YYYY-MM-DD_Insight.md
   
Layer 3  长期归档          反复出现、已成共识的，升级为原则
         MEMORY.md · 状态机/STATUS.md · 投资感悟归档/
```

**升级规则**（很重要，决定了这个目录会不会变成垃圾场）：

> 当天的想法先放 **Raw Thought**；
> 重复出现、值得执行的，提炼成 **Insight**；
> 已经形成阶段共识的，升级写进 **MEMORY / 投资感悟归档**。

不是每条想法都要往上走。大部分想法就该待在 Layer 1，那不是浪费——
**能被丢掉的想法，本来就不值得占用你的注意力。**

## 目录结构

```
BrainStorm/
├── README.md                       ← 你在这里
├── SOP_头脑风暴.md                 ← 工作流与暗号
├── MEMORY.md                       ← 长期记忆（AI 每次必读）
├── 每日头脑风暴/
│   └── Raw_Thoughts/
│       └── YYYY-MM/YYYY-MM-DD.md   ← 原始想法，按月归档
├── Summarized_Insights/
│   └── YYYY-MM/YYYY-MM-DD_Insight.md  ← AI 整理后的总结，按月归档
├── 投资感悟归档/
│   ├── 短期灵感/                   ← 单条感悟：YYYY-MM-DD_主题.md
│   ├── 长期框架/                   ← 成体系的方法论：框架名.md
│   └── 执行清单/                   ← 可勾选的操作清单：场景名.md
├── 状态机/
│   ├── STATUS.md                   ← 当前阶段状态（先看这个）
│   └── YYYY-MM/                    ← 按月归档的状态快照
└── scripts/
    └── brainstorm_memory.py        ← 上下文加载器（零依赖）
```

### 投资感悟归档的三个抽屉

这三个抽屉的区分不是形式，是**它们回答的问题不一样**：

| 抽屉 | 回答什么 | 什么时候写 | 例子 |
|:---|:---|:---|:---|
| **短期灵感** | 我今天想通了什么 | 有具体触发（一笔交易、一个事件） | `2026-07-27_卖出后不要日内买回.md` |
| **长期框架** | 我怎么系统地看这类问题 | 同一类感悟出现 3 次以上 | `核心资产判定框架.md` |
| **执行清单** | 遇到这个场景我该逐条做什么 | 框架成熟到可以勾选执行 | `退潮日减仓清单.md` |

> 顺序是 **短期灵感 → 长期框架 → 执行清单**。
> 跳过前两步直接写清单，写出来的多半是抄的，不是自己的。

## 和 YMOS 其他模块的联动

BrainStorm 不是孤立的日记本，它和投研链路是双向的：

```
        决策台留痕 ──┐
        周度复盘   ──┼──→  BrainStorm 感悟  ──→  升级为原则  ──┐
        交易复盘 P11 ┘                                        │
                                                              ▼
                                              当前关注方向与投资偏好.md
                                              击球区注册表 / 红线清单
                                                              │
                                                              ▼
                                                  P5 / P12 在下次出手时拦你
```

**具体的双向触发**：

| 从哪来 | 到哪去 |
|:---|:---|
| `Console/` 决策审计里反复出现同一条被拦记录 | → 写成短期灵感："我总在 X 情况下想违规" |
| `SOP_周度复盘` 发现连续不盈利 | → 写成感悟，并检查是不是某条框架失效了 |
| P11 交易复盘完成 | → 把心法沉淀到 `投资感悟归档/` |
| BrainStorm 里对某标的有新判断 | → 触发 `深研一下 XX`（P9+P17） |
| BrainStorm 里对板块有新洞察 | → 触发 `跑一下市场洞察` / P13 确认 |
| 感悟升级成原则 | → **回写 `持仓与关注/当前关注方向与投资偏好.md`** |

最后一条是整个闭环的关键：**感悟只有回写进偏好文件，才会真正影响下一次决策。**
否则它只是一段漂亮的自我感动。

## 快速上手

### 每天（2 分钟）

对 AI 说 **「开始今天的头脑风暴」**，它会自动加载 `MEMORY.md` + 最近 7 天的 Insight，
然后你就随便说——口语化、不用整理、语音转文字也行。**越原始越真实越好。**

聊完说 **「整理一下今天说的」**，AI 会压缩成结构化总结存档。

### 每周（10 分钟）

跑 `跑一下周度复盘`（在 `持仓与关注/SOP_周度复盘.md`），
然后回来问 AI **「复盘一下这段时间」**——它会扫最近的 Insight，提炼规律。

### 上下文加载器

```bash
python3 scripts/brainstorm_memory.py --preview      # 看看 AI 会读到什么
python3 scripts/brainstorm_memory.py --days 14      # 追溯 14 天
```

零依赖（只用标准库），路径全部相对推导，clone 下来就能跑。
`auto_summarize()` 需要 LLM client 才用得上，其余功能都不需要。

## 一条建议

刚开始用的时候，很容易觉得"我今天没什么好写的"。

那就写一句：**今天做了什么交易，为什么。** 就这一句。

三个月后你回头看，会发现最有价值的不是那些"深刻洞察"，
而是这些**当时觉得没什么可写的流水账**——因为它们诚实。
