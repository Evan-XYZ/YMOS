# 历史投资资料

这里用于放置你在使用 YMOS 之前已经积累的投资日志、复盘、感悟、旧策略和研究笔记。

## 推荐结构

```text
历史投资资料/
├── README.md
├── _模板_资料索引.md
├── 资料索引.md                  # 首次梳理时由模板复制；Git 默认忽略
├── 原始资料/                    # 放副本，保留原文件名与日期；Git 默认忽略
└── 索引与梳理/
    ├── _模板_历史资料梳理.md
    └── YYYY-MM-DD_历史资料梳理.md
```

## 怎么开始

1. 把旧资料的**副本**放进 `原始资料/`，原始文件继续保留在原位置。
2. Markdown 和纯文本最容易长期复用；PDF、Word 等格式可以保留原件，再由你的 Agent 按需生成 Markdown 转写副本。
3. 对 Agent 说“整理我的历史投资资料”，让它读取 `../SOP_历史投资资料入职.md`。
4. 先建立索引和阶段地图，不要要求一次性总结所有文件。
5. 做投资诊断时，让 Agent 先读索引，只打开与当前问题有关的代表原文。

## 隐私提醒

`原始资料/`、正式 `资料索引.md` 和生成的梳理报告默认被 Git 忽略。不要把真实账户、身份证明、API Key 或不愿公开的交易记录强行加入 Git。

如果确实想公开某篇文章，应复制到单独的公开目录并自行脱敏，不要修改这里的原件来兼顾两个用途。
