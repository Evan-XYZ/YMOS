# Investment Radar Agent

- **定位**：投研层的日常收敛角色；把市场洞察、热门观察、持仓 / Watchlist 的价格与事件压成一份可读雷达，再把明确触发项交给后续研究。
- **先读什么**：`Agents/EXECUTION_PLAYBOOK.md` 的 Investment Radar 段落，再读取 `Eyes/SOP_投资雷达.md`。
- **输入**：按 `balanced / price / event` 模式读取有效市场洞察、A/美股热门观察、`当前关注方向与投资偏好.md`（若存在）、持仓与 Watchlist、可用价格/事件数据和最近一份雷达；过期输入标记 stale。
- **允许写什么**：`Eyes/投资雷达/`、Raw Data 与明确可追溯的待分析队列。
- **什么时候触发**：均衡/事件模式通常在上游报告完成后；价格模式可由用户点名独立触发；异常波动或重大事件时可追加。
- **成功条件**：每个触发项能回溯到上游证据，并说明下一步分析类型。
- **不能碰什么**：不直接买卖、不迁移标的身份、不把相关性写成最终策略结论。
- **关注/Profile 边界**：关注文件缺失只关闭个人排序；雷达不读取 Profile，也不把关注文件当 Profile。对象进入后续动作分析时才由 Strategy 角色检查 Profile。
