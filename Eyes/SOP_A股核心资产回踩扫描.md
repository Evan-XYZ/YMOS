# SOP_A股核心资产回踩扫描

> 版本：v0.1 · 2026-05-10
> 目的：对 A 股 A 类核心资产做技术形态提醒，识别“回踩 10 日线 / 接近 10 日线 / 跌破 20 日线 / 过度远离均线”等价格事件。

---

## 1. 定位

这个 SOP 不是选股，不负责判断公司是不是好资产。

它只回答一个执行层问题：

> 核心资产库里的 A 股 A 类资产，今天有没有出现值得 Human 看一眼的技术回踩窗口？

它接在：

- 上游：`持仓与关注/核心资产库/核心资产状态机.md`
- 下游：P5 / P12 买入链审计

---

## 2. 数据源

优先复用现有问财能力：

- `Eyes/scripts/iwencai_stockpick.py`
- 问句形态：`{股票名} 最新价 10日均线 距10日均线`

实测结论：

- `股价低于10日均线` 可以返回布尔条件，但部分股票会漏 MA 字段。
- `距10日均线` 更稳定，能强制返回 `ma10[日期]`，再由脚本自行计算是否跌破。
- 多均线混合问句不稳定，所以按 MA5 / MA10 / MA20 分三次查询后合并。

已测试官方 `hithink-market-query`：可用，但本地 CLI 需要设置 `SSL_CERT_FILE=$(python3 -c 'import certifi; print(certifi.where())')`。当前先不替换既有 `iwencai_stockpick.py`，避免影响现有 What's Hot 链路。

---

## 3. 执行命令

在 YMOS 根目录下运行：

```bash
python3 Eyes/scripts/iwencai_a_pullback_scan.py
```

可选参数：

```bash
python3 Eyes/scripts/iwencai_a_pullback_scan.py \
  --near-ma10 3 \
  --near-ma20 5 \
  --extended-ma10 15
```

---

## 4. 输出路径

Raw：

```text
Eyes/A股核心资产回踩扫描/Raw_Data/YYYY-MM/a_core_pullback_YYYYMMDD.json
```

日报：

```text
Eyes/A股核心资产回踩扫描/YYYY-MM/A股核心资产回踩扫描_YYYY-MM-DD.md
```

---

## 5. 信号口径

| 信号 | 含义 | 动作 |
|:---|:---|:---|
| 🟢 回踩/跌破10日线 | 可能进入右侧回踩买点 | Human 看 K 线；必要时跑 P5/P12 |
| 🟢 接近10日线 | 距 MA10 <= 3% | 候选买点提醒 |
| 🟡 接近20日线 | 距 MA20 <= 5% | 深回踩观察，结合事件层判断是否趋势走弱 |
| 🔴 跌破20日线 | 中期趋势可能破坏 | 先复核基本面/事件，不直接抄底 |
| ⚪ 高于10日线过远 | 默认 >15% | 核心资产也不追高 |
| 👀 趋势内观察 | 未触发关键阈值 | 等下一次提醒 |

---

## 6. 验证标准

每次运行后至少检查：

1. Raw JSON 是否包含所有 A 股 A 类资产。
2. 报告表格是否有 `最新价 / MA10 / 距MA10 / MA20 / 距MA20 / 信号`。
3. 如果出现 `⚪ 数据不足`，先检查问财是否漏返回 MA 字段；必要时用 `距10日均线` 单问句重试。

---

## 7. Cron 建议

这个扫描适合 A 股盘后或午后跑：

- 午间：北京时间 11:35，识别上午回踩
- 盘后：北京时间 15:10，作为收盘后买点提醒

建议先手动跑 2-3 天，确认问财稳定性后再上 cron。
