# 美股热门追踪：动量与 A 股映射 SOP（公开版）

> 暗号：`跑一下美股热门追踪` / `美股热门追踪`
> 输出：`Eyes/美股热门追踪/YYYY-MM/美股热门追踪_YYYY-MM-DD.md`
> 下游：`Eyes/SOP_美股热门观察.md`，并作为 A 股 What's Hot 的跨市场输入

## 1. 目标

美股热门追踪回答四个问题：

1. 刚结束的美股交易日，大市值公司与主要行业发生了什么？
2. 哪些方向是首次启动，哪些正在延续或创新高？
3. 上涨和下跌分别由财报、指引、宏观、产业事件还是纯价格动量驱动？
4. 哪些信号能映射到 A 股，哪些只能作为美股背景？

美股侧以“信号源 + 映射源”为主，不需要把每只股票做成深度资产评级。个人持仓、观察池和偏好只能在全市场扫描完成后用于排序与关联提示，不得收窄扫描范围。

## 2. 输入与依赖

- `Eyes/scripts/iwencai_us_stockpick.py`
- 最近 3-7 份 `Eyes/市场洞察/YYYY-MM/`
- 最近 1-3 份 `Eyes/A股热门观察/YYYY-MM/` 或 `Eyes/Whats_Hot/YYYY-MM/`
- 最近 3-5 份 `Eyes/美股热门观察/YYYY-MM/`
- 可选：Finnhub、公司 IR/SEC、公开搜索、用户自定义关注配置

缺少用户配置不影响全市场扫描；缺少问财时允许 best-effort，但不得伪造池数量与行业广度。

## 3. 市场环境与三条观察线

先判断：

| 轴 | 状态 |
|:---|:---|
| 中期路径 | 趋势扩张 / 高位震荡 / 深度回撤 / 底部修复 |
| 当日环境 | 普涨 / 结构分化 / 缩量 / 恐慌 / 高波动 |

再选择观察线：

| 观察线 | 回答什么 | 默认启用 |
|:---|:---|:---:|
| 异动线 | 今天什么在涨跌，大票与行业在奖励/惩罚什么 | 是 |
| 新高线 | 什么在持续走趋势，行业构成偏进攻还是避险 | 趋势扩张、高位震荡优先 |
| 启动线 | 什么前期不强、今天开始被资金选择 | 底部修复、区间轮动优先 |

三条线不是封闭分类。出现整条产业链估值重定价、宏观冲击或其他覆盖不到的结构时，报告单列说明。

## 4. 查询模板

统一字段包：

```text
显示成交额、换手率、所属行业、所属概念
```

| ID | 用途 | 模板 |
|:---|:---|:---|
| U01 | 涨幅异动 | `{DATE}美股，市值大于{MV}亿美元，涨幅大于{UP}%，{FP}` |
| U02 | 跌幅异动 | `{DATE}美股，市值大于{MV}亿美元，跌幅大于{DOWN}%，{FP}` |
| U03 | 60 日新高 | `{DATE}美股，市值大于{MV}亿美元，股价创60日新高，涨跌幅大于0，{FP}` |
| U04 | 大市值上涨 | `{DATE}美股，市值大于{MEGA}亿美元，涨幅大于3%，{FP}` |
| U05 | 行业涨幅榜 | `{DATE}美股行业涨跌幅排名前20，显示行业名称、涨跌幅、成交额` |
| U06 | 1 年新高 | `{DATE}美股，市值大于{MV}亿美元，股价创1年新高，涨跌幅大于0，{FP}` |
| U07 | 20 日强势 | `{DATE}美股，市值大于{MV}亿美元，近20日涨幅大于20%，涨跌幅大于0，{FP}` |
| U08 | 大市值下跌 | `{DATE}美股，市值大于{MEGA}亿美元，跌幅大于3%，{FP}` |
| U09 | 窗口新高 | `{DATE}美股，市值大于{MV}亿美元，近2周股价创60日新高，涨跌幅大于0，{FP}` |

默认参数：`UP=5`、`DOWN=5`、`MV=100`、`MEGA=500`。允许涨跌幅 3% / 5% / 8%，市值下限不低于 50 亿美元。美股字段中不要写 A 股的“量比”或“所属同花顺行业”；执行后以实际返回字段为准。

每次运行必须保存 query、交易日期、`code_count`、`returned_count`、完整抓取状态和返回字段。翻页抓全，并检查目标日期涨跌幅列与创新高证明列。缺失证明列时该池作废，不能因为 API 返回 OK 就继续使用。

## 5. 扫描和本地计算

### 5.1 基座必跑

U01、U02、U04、U08、U05。它们回答“昨夜到底发生了什么”。

### 5.2 新高线

常用 U03，严苛 U06，连续爆发或希望扩大覆盖时加 U09。本地计算同日命中新高档位的深度；如有历史 Raw，可统计过去 20 个交易日进入 U03 的次数。

不要只看股票名单，还要统计新高池的行业构成：金融、公用事业和消费防御占主导，与半导体、软件和周期行业占主导，代表完全不同的风险偏好。

### 5.3 启动线

用 U01 排除 U07，寻找前期不在 20 日强势池、当天首次明显异动的股票；再要求同方向至少 2-3 只同步或存在可核验硬催化。孤立无归因的大涨不能升级为方向启动。

### 5.4 负向线

同时检查：

- U02/U08 的集中行业与大市值下跌。
- 同行业涨跌两端同时出现的内部再定价。
- 财报或指引看似不错但股价下跌的“利好兑现杀”。
- 连续剧中的主线是否出现广度收缩、领导股破位或映射失效。

“没有继续上涨”默认是待评估，不自动等于退潮。

## 6. 归因与三档裁决

| 档位 | 条件 | 处理 |
|:---|:---|:---|
| 强信号 | 价格事件明确 + 归因明确 + 能说明 A 股映射或明确无映射 | 进入主表与映射层 |
| 观察 | 价格明确，但归因或映射只完成一部分 | 标记待验证 |
| 噪音/证伪 | 无法归因，或原有逻辑已被价格/事实否定 | 降级或只进负向表 |

归因优先级：公司财报/IR 与 SEC → 政府或监管原文 → Finnhub 与主流财经媒体 → 其他公开检索。每个强信号至少保留一条可追溯催化证据。

A 股映射不是强行找同名概念，而是写清传导链：美股公司/行业发生什么 → 需求落在哪个收入或资本开支环节 → A 股哪些产业环节可能验证 → 尚缺什么价格或订单证据。说不清时直接写“暂无明确 A 股映射”。

## 7. 执行顺序

1. 确定刚结束的美股交易日，区分市场日期与北京时间。
2. 读取最近市场洞察、A/美股连续剧和用户可选关注配置。
3. 判断市场环境，决定新高线和启动线是否加跑。
4. 执行基座池并校验完整性；根据环境加跑 U03/U06/U07/U09。
5. 按实际行业字段和概念字段做本地聚类，不凭印象估算广度。
6. 完成上涨与下跌归因、关注层标注和 A 股映射。
7. 生成报告；同日重跑保留备份或可恢复版本。

## 9. 输出与自检

报告：`Eyes/美股热门追踪/YYYY-MM/美股热门追踪_YYYY-MM-DD.md`

落盘前确认：交易日期正确；池已抓全或明确标记不完整；每个强结论有价格与归因证据；关注配置没有过滤全市场；上涨与下跌都完成归因；映射链没有硬凑；没有把动量直接写成买卖动作。
