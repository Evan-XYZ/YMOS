# 美股热门追踪：动量与 A 股映射 SOP（公开版）

> 暗号：`跑一下美股热门追踪` / `美股热门追踪`
> 输出：`Eyes/美股热门追踪/YYYY-MM/美股热门追踪_YYYY-MM-DD.md`
> 下游：`Eyes/SOP_美股热门观察.md`，并作为 A 股 What's Hot 的跨市场输入

## 1. 目标

美股热门追踪回答四个问题：

1. 刚结束的美股交易日，大市值公司与主要行业发生了什么？
2. 哪些方向是首次启动，哪些正在延续或创新高？
3. 上涨和下跌分别由财报、指引、宏观、产业事件还是纯价格动量驱动？
4. 哪些信号能映射到 A 股，哪些只能作为美股背景？

美股侧以“信号源 + 映射源”为主，不需要把每只股票做成深度资产评级。个人持仓、观察池和偏好只能在全市场扫描完成后用于排序与关联提示，不得收窄扫描范围。

## 2. 输入与依赖

- `Eyes/scripts/iwencai_us_stockpick.py`
- 最近 3-7 份 `Eyes/市场洞察/YYYY-MM/`
- 最近 1-3 份 `Eyes/A股热门观察/YYYY-MM/` 或 `Eyes/Whats_Hot/YYYY-MM/`
- 最近 3-5 份 `Eyes/美股热门观察/YYYY-MM/`
- 可选：Finnhub、公司 IR/SEC、公开搜索、用户自定义关注配置

缺少用户配置不影响全市场扫描；缺少问财时允许 best-effort，但不得伪造池数量与行业广度。

### 2.1 基本面事件源识别（必须）

归因前先确定 `event_source_mode`，只检查凭据是否存在和输出是否健康，不得输出 Key：

| 顺序 | 模式 | 使用条件 | 处理 |
|:---:|:---|:---|:---|
| 1 | `market_api` | 存在 `YMOS_MARKET_API_KEY`，且 Market API Raw 可解析、非空、日期匹配 | 作为市场/产业事件增量 |
| 2 | `local_market_insight` | API 未配置/失败，但本地有时间有效的市场洞察 | 复用其事实、来源与日期 |
| 3 | `rss_local` | 上述均不可用且 `fetch_rss.py` 可运行 | Raw 落本任务目录并保留逐源状态 |
| 4 | `company_primary` | 对强价格候选补归因 | 公司 IR、财报新闻稿、SEC/监管原文优先 |
| 5 | `price_only` | 事件源均不可用 | 保留价格和行业事实，归因标“待确认” |

`FINNHUB_API_KEY` 若存在可补 company-news，但不是主任务前置。无 Market API Key 是正常降级；脚本 exit 0 却没有有效输出也不能视为成功。报告需记录最终模式、数据截至、覆盖和失败层级。

## 3. 市场环境与三条观察线

先判断：

| 轴 | 状态 |
|:---|:---|
| 中期路径 | 趋势扩张 / 高位震荡 / 深度回撤 / 底部修复 |
| 当日环境 | 普涨 / 结构分化 / 缩量 / 恐慌 / 高波动 |

再选择观察线：

| 观察线 | 回答什么 | 默认启用 |
|:---|:---|:---:|
| 异动线 | 今天什么在涨跌，大票与行业在奖励/惩罚什么 | 是 |
| 新高线 | 什么在持续走趋势，行业构成偏进攻还是避险 | 趋势扩张、高位震荡优先 |
| 启动线 | 什么前期不强、今天开始被资金选择 | 底部修复、区间轮动优先 |

三条线不是封闭分类。出现整条产业链估值重定价、宏观冲击或其他覆盖不到的结构时，报告单列说明。

## 4. 查询模板

统一字段包：

```text
显示成交额、换手率、所属行业、所属概念
```

| ID | 用途 | 模板 |
|:---|:---|:---|
| U01 | 涨幅异动 | `{DATE}美股，市值大于{MV}亿美元，涨幅大于{UP}%，{FP}` |
| U02 | 跌幅异动 | `{DATE}美股，市值大于{MV}亿美元，跌幅大于{DOWN}%，{FP}` |
| U03 | 60 日新高 | `{DATE}美股，市值大于{MV}亿美元，股价创60日新高，涨跌幅大于0，{FP}` |
| U04 | 大市值上涨 | `{DATE}美股，市值大于{MEGA}亿美元，涨幅大于3%，{FP}` |
| U06 | 1 年新高 | `{DATE}美股，市值大于{MV}亿美元，股价创1年新高，涨跌幅大于0，{FP}` |
| U07 | 20 日强势 | `{DATE}美股，市值大于{MV}亿美元，近20日涨幅大于20%，涨跌幅大于0，{FP}` |
| U08 | 大市值下跌 | `{DATE}美股，市值大于{MEGA}亿美元，跌幅大于3%，{FP}` |
| U09 | 窗口新高 | `{DATE}美股，市值大于{MV}亿美元，近2周股价创60日新高，涨跌幅大于0，{FP}` |

默认参数：`UP=5`、`DOWN=5`、`MV=100`、`MEGA=500`。允许涨跌幅 3% / 5% / 8%，市值下限不低于 50 亿美元。美股字段中不要写 A 股的“量比”或“所属同花顺行业”。

### 4.1 美股字段契约（2026-08-14 实测）

U01/U02/U03/U04/U06/U08/U09 的个股池稳定返回：`股票代码`、`股票简称`、`总市值[DATE]`、`流通市值[DATE]`、`涨跌幅:前复权[DATE]`、`成交额[DATE]`、`换手率[DATE]`、`三级行业分类`、`最新价`、`最新涨跌幅`；`所属概念` 本次可用，但视为**可选字段**，缺失不能让整池失败。U07 额外返回近 20 日区间涨跌幅列。

query 写“所属行业”，结果取 `三级行业分类`；不得改读 A 股的 `所属同花顺行业`。`距新高`、`新高档深`、`持续度`、`拥挤度`都不是问财直接字段，必须由 U03/U06/U07/U09 集合、历史 Raw 或价格序列本地计算；缺输入时留空，不得猜数。

问财的美股行业涨幅榜问句已经移除：实测虽 `exit=0`、返回 20 行，但 `chunks_info` 与 `成分领域` 都指向 `A股指数`。行业分析改为对 U01/U02/U04/U08 的 `三级行业分类` 做本地计数，名称必须写“异动行业广度”，不能冒充全市场行业涨幅榜；需要真正行业指数时必须换用另一个已验证数据源。

每次运行必须保存 query、交易日期、`code_count`、`returned_count`、完整抓取状态、`chunks_info` 和返回字段。翻页抓全，并先做市场防串线校验：股票代码不得以 `.SH/.SZ/.BJ` 结尾，返回键不得含 A 股专用字段，`成分领域`/`chunks_info` 不得出现 `A股指数`。命中任一项，该池即作废。

新高池再按以下两级证据校验：

1. **优先逐行证明**：返回字段含目标日期的“创新高条件说明 / 最高价创新高”等证明列。
2. **美股接口兼容证明**：若接口不返回逐行证明列，`chunks_info` 必须明确包含目标交易日、`选美股` 和对应“60 日 / 1 年新高”筛选条件，同时结果必须含目标日期涨跌幅列、非 A 股代码与美股行业字段。

两级证据都不满足时该池作废。不能只因为 API 返回 OK 或结果数量看起来合理就继续使用；报告查询审计表要写明本次采用“逐行证明”还是“query 条件证明”。

## 5. 扫描和本地计算

### 5.1 基座必跑

U01、U02、U04、U08。它们回答“昨夜到底发生了什么”。随后按 `三级行业分类` 本地统计上涨异动数、下跌异动数、大市值上涨数和大市值下跌数，形成异动行业广度。

### 5.2 新高线

常用 U03，严苛 U06，连续爆发或希望扩大覆盖时加 U09。本地计算同日命中新高档位的深度；如有历史 Raw，可统计过去 20 个交易日进入 U03 的次数。

不要只看股票名单，还要统计新高池的行业构成：金融、公用事业和消费防御占主导，与半导体、软件和周期行业占主导，代表完全不同的风险偏好。

### 5.3 启动线

用 U01 排除 U07，寻找前期不在 20 日强势池、当天首次明显异动的股票；再要求同方向至少 2-3 只同步或存在可核验硬催化。孤立无归因的大涨不能升级为方向启动。

### 5.4 负向线

同时检查：

- U02/U08 的集中行业与大市值下跌。
- 同行业涨跌两端同时出现的内部再定价。
- 财报或指引看似不错但股价下跌的“利好兑现杀”。
- 连续剧中的主线是否出现广度收缩、领导股破位或映射失效。

“没有继续上涨”默认是待评估，不自动等于退潮。

## 6. 归因与三档裁决

| 档位 | 条件 | 处理 |
|:---|:---|:---|
| 强信号 | 价格事件明确 + 归因明确 + 能说明 A 股映射或明确无映射 | 进入主表与映射层 |
| 观察 | 价格明确，但归因或映射只完成一部分 | 标记待验证 |
| 噪音/证伪 | 无法归因，或原有逻辑已被价格/事实否定 | 降级或只进负向表 |

归因优先级：公司财报/IR 与 SEC → 政府或监管原文 → Finnhub 与主流财经媒体 → 其他公开检索。每个强信号至少保留一条可追溯催化证据。

A 股映射不是强行找同名概念，而是写清传导链：美股公司/行业发生什么 → 需求落在哪个收入或资本开支环节 → A 股哪些产业环节可能验证 → 尚缺什么价格或订单证据。说不清时直接写“暂无明确 A 股映射”。

## 7. 执行顺序

1. 确定刚结束的美股交易日，区分市场日期与北京时间。
2. 识别基本面事件源并记录 `event_source_mode`、日期与降级状态。
3. 读取最近市场洞察、A/美股连续剧和用户可选关注配置。
4. 判断市场环境，决定新高线和启动线是否加跑。
5. 执行 U01/U02/U04/U08 并校验完整性；根据环境加跑 U03/U06/U07/U09；不得调用行业涨幅榜问句。
6. 以 `三级行业分类` 为主、可用时以 `所属概念` 为辅做本地聚类；输出称“异动行业广度”，不凭印象估算，也不冒充行业指数涨幅榜。
7. 完成上涨与下跌归因、关注层标注和 A 股映射。
8. 生成报告；同日重跑保留备份或可恢复版本。
