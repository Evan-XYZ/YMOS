## 一句话定位

**美股热门追踪 = 美股价格事件层（市场提前派发的研究任务）**——把"异动 + 新高"两层价格信号 + 当日/7 天市场洞察 + P14-lite 板块热度镜头做共振判断，**先量化打分，再写判断**，再用 P17 v3 把候选标的拆成 **资产等级（A类核心/A类高赔率/B类跟踪）** 与 **当前机会（抢筹初期/待回调/Conditional）**。产出先进入 `持仓与关注/美股观察/` 的 Human-in-the-loop 观察池；A 类默认进入自动建档补证据链，B 类/需价格跟踪标的经 Human 确认或连续入池后进入 `动态Watchlist/`。

### 统一链路契约（2026-05-11）

本 SOP 只负责链路第一段：**动量发现**。它不能把价格强弱直接翻译成买点，也不能把热门初筛直接当最终资产等级。

```text
价格事件（异动 / 新高 / 跌幅）
  → 基本面证据链（市场洞察 + Finnhub/IR/SEC/财报/订单）
  → P14-lite 判断主线与真龙头
  → P17 v3 判断资产等级 + 当前机会标签
  → 美股观察状态机（A 类待自动建档；B 类待确认/价格跟踪候选）
  → Watchlist 自动建档补 P1/P2/P4/P9/P17 证据
  → 核心资产动态判定表做周度升降级与 Q6 刷新
```

关键口径：
- 动量不是买点信号，而是“市场提前派发的研究任务”。
- A 类资产不等于当前可以买；当前机会必须由 `Q6 阶段 + P9 安全边际 + 催化证据 + 价格位置` 决定。
- 美股热门追踪可以发现非 AI 的 PVE 新方向；AI 是重心，不是过滤边界。
- 本 SOP 的输出必须能被 Watchlist 自动建档和核心资产动态判定表无损消费。

> 重要校准（2026-05-10）：AI 产业链是当前研究重心，但美股热门追踪不是 "AI filter"。它的任务是识别**市场正在抢筹的非对称创新资产**：AI 基建 / 半导体 / 存储 / Neocloud 是主线，商业航天、核聚变、机器人、能源、电力、量子、硬科技平台等只要出现价格事件 + 基本面催化 + P17 正反馈，也必须进入 A/B 队列。

```text
异动池（>10% 单日）+ 新高池（持续抢筹）
  + 当日 / 7 天市场洞察（基本面事件）
  + P14-lite 美股板块热度镜头（主题收敛 / 龙头识别 / 跟风剔除 / 退潮）
  + A 股 What's Hot 仅作弱参考（美股主导，不反向被 A 股牵引）
  + AI 产业链 INDEX-v2 (P17 快判矩阵)
  + 非 AI 非对称创新白名单（商业航天 / 核聚变 / 机器人 / 能源 / 电力 / 量子等）
  + 已有持仓 / Watchlist 去重
= 量化打分 Score → P17 v3 六问 → A / B / 跳过 三档
= 美股热门追踪日报 + 美股观察池候选 + 美股观察状态机 + Watchlist 自动建档候选
```

### 2026-05-10 v3 校准：A类资产不等于A类买点

美股热门追踪里的 A/B 不再只表示“马上买/等回调”，而先表示**资产优先级**：

- **A类资产**：长期核心资产（利润池清晰、份额可捕获）或高赔率战略稀缺资产（终局空间大但验证更敏感）。默认自动建档并进入 `核心资产库`。
- **B类资产**：资产质量或稀缺性弱于 A 类，但存在估值 gap、事件催化或主题发酵价值。默认进入跟踪候选。
- **当前机会标签**：单独输出 `🚀 抢筹初期 / 👀 待回调 / 🟡 Conditional / 🔴 跳过`。A类资产当前也可能是 `👀 待回调`。

报告必须同时写：`资产等级` + `当前机会标签`，并把 A/B 资产同步到 `持仓与关注/核心资产库/核心资产状态机.md`，供 `SOP_核心资产动态判定表.md` 后续刷新。

## ⚙️ 完整执行步骤

### Step 1：加载市场背景（自持增量 + 3~7 天市场洞察）

> 2026-05-10 修订：本 SOP **不再依赖“当日市场洞察已生成”**，也不触发 `跑一下市场洞察`。市场洞察按自己的节奏运行；美股热门追踪只读取已有报告，并按“上一份美股热门追踪报告 mtime → 当前时间”的窗口，独立抓取本 SOP 所需的基本面事件增量。

**1.0 计算本 SOP 自己的增量窗口 `LOOKBACK_DAYS`**

```bash
LATEST_US_HOT=$(ls -1 "Eyes/美股热门追踪/"*/美股热门追踪_????-??-??.md 2>/dev/null | sort | tail -1)
if [ -z "$LATEST_US_HOT" ]; then
  LOOKBACK_DAYS=1
else
  LOOKBACK_DAYS=$(python3 -c "import os,time; m=os.path.getmtime('$LATEST_US_HOT'); print(f'{max(0.5, round((time.time()-m)/86400, 2)):.2f}')")
fi
echo "上一份美股热门追踪：${LATEST_US_HOT:-无} | LOOKBACK_DAYS=$LOOKBACK_DAYS"
```

**1.1 独立抓取基本面事件增量（存到美股热门追踪自己的 Raw_Data）**

```bash
python3 Eyes/scripts/fetch_market_api.py $LOOKBACK_DAYS   --output "Eyes/美股热门追踪/Raw_Data/YYYY-MM/market_increment_YYYYMMDD.json"

python3 Eyes/scripts/fetch_finnhub_news.py   --hours $(python3 -c "print(int(float('$LOOKBACK_DAYS') * 24))")   --output "Eyes/美股热门追踪/Raw_Data/YYYY-MM/finnhub_increment_YYYYMMDD.json"
```

若任一增量抓取失败：保留 status/错误说明，降级为读取最近 3~7 天市场洞察；**不要补跑市场洞察**。

**1.2 过去 3~7 天市场洞察（只读已有报告）**：提取
- 重复出现的主线（势能在哪）
- 新强化的主题（新机会方向）
- 衰退中的主题（即将退潮）
- 事件链条与背景解释

**1.3 最近可用 What's Hot（如已生成）**：`Eyes/Whats_Hot/YYYY-MM/Whats_Hot_YYYY-MM-DD.md`。注意运行时差：美股热门追踪通常在北京时间 04:30 跑，A股 What's Hot 是 A股收盘后当天跑，所以美股报告默认读取**最近一个已完成 A股交易日**的 What's Hot（通常是前一日或最近交易日），而不是强行要求同日文件。它只作弱参考：A 股对美股的解释力有限，不能因为 A 股没反应而降权美股 A/B 候选；若 A 股已提前映射，可标记为“跨市场共振”。

**1.4 美股观察状态机（写回目标）**：`持仓与关注/美股观察/美股Watchlist状态机.md`。本 SOP 结束时必须把 A/B 候选、Human状态、建档状态、价格跟踪候选写回该状态机，供 Watchlist 自动建档消费。

**1.5 产业链快判矩阵（可选）**：如果你维护了自己的产业链索引文件，把它作为"已做过 P17 判定"的参考读入

**1.6 非 AI 非对称创新白名单（新增 2026-05-10）**：避免 Agent 因用户近期强调 AI 产业链而把其他大机会误杀。白名单包括：
- 商业航天 / Space economy（发射服务、卫星星座、地面站及未上市巨头的映射标的）
- 核聚变 / 新能源终局电力（聚变、SMR、核电供应链、电网）
- 机器人 / 自动化 / 具身智能
- 量子 / 国防科技 / 硬科技平台
- 其他满足"大 TAM + 早期势能 + 稀缺资产 + 可被市场持续交易"的 PVE 增量赛道

原则：**AI 是重心，不是边界；市场驱动不是用我的偏好过滤市场，而是让市场告诉我哪里正在形成新势能。**

### Step 2：跑三个池子（异动 + 新高 + 跌幅）

#### 2.1 异动池（强势 · 单日 >10%）

**Query**：

```text
美股 今日涨幅大于10%，市值大于30亿美元
```

**执行**：

```bash
python3 Eyes/scripts/iwencai_us_stockpick.py \
  '美股 今日涨幅大于10%，市值大于30亿美元' \
  --json-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_movers_YYYYMMDD.json \
  --csv-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_movers_YYYYMMDD.csv \
  --desc-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_movers_YYYYMMDD_description.txt \
  --status-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_movers_YYYYMMDD_status.txt \
  --limit 50
```

**用途**：捕捉**单日突发性事件触发的强信号**——财报 / 大客户合同 / 监管 / 收购等。

#### 2.2 新高池（持续抢筹 · 60 日 + 1 年新高）

**Query**：

```text
美股 市值大于30亿美元，近2周股价创60日新高，近1月创1年新高，近5个交易日上涨大于3%
```

**执行**：

```bash
python3 Eyes/scripts/iwencai_us_stockpick.py \
  '美股 市值大于30亿美元，近2周股价创60日新高，近1月创1年新高，近5个交易日上涨大于3%' \
  --json-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_newhighs_YYYYMMDD.json \
  --csv-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_newhighs_YYYYMMDD.csv \
  --desc-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_newhighs_YYYYMMDD_description.txt \
  --status-out Eyes/美股热门追踪/Raw_Data/YYYY-MM/us_newhighs_YYYYMMDD_status.txt \
  --limit 50 --max-pages 4
```

**用途**：捕捉**持续抢筹但单日不一定异动**的早期上涨——这是错过 INTC 类机会的关键池。新高策略可以拿到 100-200 只标的，是异动池的 5x 量。

#### 2.3 跌幅池（持仓预警 · 不进 Watchlist）

**Query**：

```text
美股 今日跌幅大于10%，市值大于30亿美元
```

**用途**：**只用于持仓预警和 B 类回调监测，不产 Watchlist 候选**。
- 持仓 ∩ 跌幅池 → 立即触发 P6 持有评估
- B 类 Watchlist 标的 ∩ 跌幅池 → 投资雷达高亮回调买点
- 板块层资金流出 → 已被 What's Hot 覆盖，不重复

### Step 4.5：P14-lite 板块热度镜头（借鉴 A 股 What's Hot，但不整套照搬）

美股热门追踪最终目标仍是找 **A/B 两类投资机会**，不是写板块综述；但要借鉴 `SOP_Whats_Hot.md` 的 P14 有用逻辑，给每只候选加一层“它是不是资金选出来的真主线/真龙头”。

**只提取 P14 的四个有效动作**：
1. **主题收敛**：异动池 / 新高池里是否有多个独立标的指向同一板块？如 AI 算力、存储、商业航天、电力、核能。
2. **龙头识别**：同一板块里谁是资金真正选择的龙头，谁只是跟风补涨。
3. **高影响异常**：是否出现“重大消息 + 罕见价格动作”的个股，例如财报超预期、合同、监管放行、机构上调。
4. **退潮/背离**：强势板块内部是否出现跌幅池命中、高位滞涨或龙头弱于跟风。

**输出要求**：在日报中新增“🌡️ 美股板块热度层”小节，只写 3-5 行高密度判断：
- 今日最强板块：
- 真龙头 / 跟风股：
- 与 7 天市场洞察主线是否共振：
- 退潮/背离风险：

**边界**：不要为了跑 P14 而写长篇板块报告；P14-lite 只服务于 A/B 分类与噪音剔除。

### Step 5：量化打分层（新增 2026-05-10 · 先量化，再判断）

在进入完整 P17 六问前，对候选标的统一打分，避免报告被个人偏好或叙事惯性带偏。

#### 5.1 总分公式（100 分基础 + 风险扣分）

```text
Score = PriceEvent(0-20)
      + MomentumPersistence(0-15)
      + CatalystEvidence(0-20)
      + CoreAssetScarcity(0-20)
      + FutureOptionality(0-10)
      + PortfolioFit(0-10)
      + NewDiscoveryBonus(0-5)
      - RiskPenalty(0-20)
```

| 因子 | 分值 | 判定方式 |
|:---|---:|:---|
| PriceEvent | 0-20 | 异动池 +8；新高池 +8；双池命中额外 +4。双池满分代表当日抢筹强度，不代表资产等级更高 |
| MomentumPersistence | 0-15 | 5 日 / 2 周 / 1 月趋势是否持续；不是单日脉冲 |
| CatalystEvidence | 0-20 | Finnhub company-news / 新闻 / 财报 / 订单 / 指引 是否能解释价格事件 |
| CoreAssetScarcity | 0-20 | P17 Q1 + Q4：核心资产 + 稀缺性；INDEX 第一梯队可先给高分，但非 INDEX 不默认低分 |
| FutureOptionality | 0-10 | 3-5 年终局空间、TAM、产业位置、SpaceX/AI/电力等后续大事件映射 |
| PortfolioFit | 0-10 | 是否与持仓 / Watchlist / 当前研究主线相关；持仓相关用于预警，不重复建档 |
| NewDiscoveryBonus | 0-5 | INDEX 外但明显处于新兴 PVE 赛道的早期发现加分，如商业航天 / 核聚变 |
| RiskPenalty | 0-20 | 财务爆雷、现金流/融资风险、一次性 meme、监管/临床二元事件、估值已透支等扣分 |

#### 5.2 分层阈值

| 分数 | 队列 | 含义 |
|:---|:---|:---|
| ≥75 | P0 / A 类候选 | 立即进入观察池并默认触发自动建档补证据链；是否买入仍需 P5/P12 + Human |
| 60-74 | P1 / B 类候选 | 进入观察池；只有 Human 确认、连续入池或 P17 明确需要价格跟踪后，才进动态 Watchlist 等回调 / 等证据 |
| 45-59 | P2 观察 | 暂不建档；若连续 3 次入池或出现新催化再升级 |
| <45 | 跳过 | 噪音 / 非当前可执行机会 |

#### 5.3 非 AI 机会的打分校准

非 AI 标的不因"不属于 AI 产业链"扣分。只有在以下情况降权：
- 没有明确 PVE 增量空间；
- 价格事件无法被新闻/财报/订单解释；
- 只是短线 meme / squeeze，缺核心资产与终局空间。

商业航天、核聚变、能源电力、机器人等如果出现：
`异动 + 新高 + 明确催化 + 未来 3-5 年大事件 + 稀缺资产`，应按 A/B 规则正常进入队列。

#### 5.4 Finnhub 个股新闻 / 财报搜索层

对 P0 + P1 队列，必须补一层异动原因检索：

```bash
# 已在持仓/动态 Watchlist 的标的：直接复用市场洞察 Finnhub 输出
Eyes/市场洞察/Raw_Data/YYYY-MM/finnhub_news_YYYYMMDD.json

# 热门追踪新发现但尚未进入 Watchlist 的标的：用 Web/IR 补足催化，或先进入建档队列后由 Watchlist 自动建档补拉
```


执行优先级：
1. **Finnhub company-news**：`Eyes/scripts/fetch_finnhub_news.py --include-watchlist` 生成的 `finnhub_news_YYYYMMDD.json`
2. 公司 IR / SEC filings / 财报新闻稿 / 主流财经新闻

4. 问财字段中的新闻 / 财报解释（如返回）

输出要求：每个 P0/P1 标的至少写一句 `CatalystEvidence`：
- ✅ 有明确催化：财报 / 指引 / 订单 / 合同 / 政策 / 分析师上调 / 产业事件
- 🟡 催化不完整：只有价格，没有足够新闻解释 → 降为 B/P2
- 🔴 催化证伪：利好不可持续或一次性 → 跳过

## ⚠️ 边界与反模式

**美股热门追踪 不做**：
- 不直接输出买卖建议（产 Watchlist 候选，建仓走 P5 + P17 v2 + P12）
- 不替代投资雷达（雷达跟踪已有 Watchlist 价格变化）
- 不替代 What's Hot（A 股板块视角）

**反模式**：
- 看到 >10% 就追（80% 该被噪音剔除）
- 把短期投机性异动当核心资产被重新发现
- 跳过 P17 v2 六问直接加 Watchlist
- 把 B 类机会当 A 类立即建仓（混淆"已涨多需等回调" vs "仍在右侧初期"）
- 用熊市心智去判 Q5 牛市视角（导致 A 类全被压成 B 类，错过抢筹机会）
