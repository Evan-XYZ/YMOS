# SOP_问财个股财务数据查询

## 1. 定位

问财个股财务数据查询用于补足 YMOS 的“确定性财务指标层”。

它不是用来替代投资判断，而是用于减少基础调研里的错误率：

- 营业收入、归母净利润、毛利率、净利率；
- ROE / ROA / 加权 ROE；
- 资产负债率、现金流；
- 收入同比、利润同比；
- 估值指标（PE/PB/PS 等，视问句返回）。

和研报搜索的区别：

- 研报搜索 = 市场叙事层 / 券商偏好 / 估值锚点；
- 财务数据查询 = 结构化事实层 / 财务快照 / P9 输入项。

优先级：公告/财报原文 > 问财结构化财务数据 > 搜索摘要/网页摘要。

## 2. 本机安装位置

SkillHub 官方技能已安装：

```bash
<SKILL_ROOT>/hithink-finance-query
<SKILL_ROOT>/hithink-finance-query/scripts/cli.py
```

环境变量位于 shell profile：

```bash
~/.zprofile
~/.zshrc
```

包含：

```bash
IWENCAI_BASE_URL=...
IWENCAI_API_KEY=...
```

注意：不要把 API Key 写入 Obsidian 文件或报告正文。

## 3. YMOS 封装脚本

统一使用封装脚本：

```bash
cd "<你的 YMOS 根目录>"
python3 Eyes/scripts/iwencai_finance_query.py "大族激光 2026一季报 营业收入 净利润 毛利率 净利率 ROE 资产负债率 经营现金流" -l 3
```

也可以只传股票名，脚本会自动补默认指标：

```bash
python3 Eyes/scripts/iwencai_finance_query.py "大族激光" -l 3
```

默认指标：

```text
营业收入 净利润 毛利率 净利率 ROE 资产负债率 经营现金流 营收同比 净利润同比
```

输出：

```bash
Eyes/财务数据查询/Raw_Data/YYYY-MM/finance_query_[query]_YYYYMMDD.json
Eyes/财务数据查询/YYYY-MM/财务数据_[query]_YYYY-MM-DD.md
```

## 4. macOS 证书坑

官方 CLI 在 macOS 上可能报：

```text
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed
```

YMOS 封装脚本已经自动注入 `certifi` 的 `SSL_CERT_FILE`。如果直接调用官方 CLI，使用：

```bash
SSL_CERT_FILE=$(python3 -c 'import certifi; print(certifi.where())') \
python3 <SKILL_ROOT>/hithink-finance-query/scripts/cli.py \
  -q "大族激光 2026一季报 营业收入 净利润 毛利率 ROE" --limit 3
```

```text

```

```text

```

```text
[公司名] 近三年 营业收入 净利润 经营现金流 毛利率 ROE
```

## 6. 在 YMOS 中怎么用

### 自动建档

用于：

- `P1 基础快照`：收入、利润、利润率、现金流；
- `P2 阶段判断`：增速是否兑现，是否进入业绩加速期；
- `P9 估值分析`：市值/收入/利润/利润率输入；
- `P1/P3/P16`：补充财务事实、事件影响与财报审计，避免只看叙事。

### 策略分析

用于：

- 买入前 P5/P9 的财务输入；
- 持仓复核时判断“叙事是否开始兑现到财务”；
- 对高估值标的检查增长是否支撑估值。

### 周期性财务复核

用于：

- 周度巡检的财务状态更新；
- 财报季后刷新关键指标、原论点与可证伪信号；
- 对“价格强但财务弱”的标的打 `pending_review`。

## 7. 使用纪律

1. 财务数据查询是事实层，不是买入信号。
2. 关键决策前，重要字段仍要回公告/财报核验。
3. 问句要明确报告期，否则容易返回“最新一期”但口径不清。
4. 若字段缺失，先简化问句，不要强行脑补。
5. 对 A 股自动建档，优先使用财务数据查询 + 研报搜索双层输入：一个管事实，一个管叙事。
