# 投资雷达｜脱敏示例

> **合成场景：** 上游市场洞察发现“AI 定价从叙事切向订单、融资和交付”，本报告演示 YMOS 如何把宏观线索映射到持仓、Watchlist 与下一步研究。
> 所有标的均为虚构代号：DEMO-H、DEMO-A、DEMO-B，不构成证券推荐。

**覆盖结果：** 1 个模拟持仓、3 个模拟关注标的、2 个市场温度计全部有价格或明确缺失原因。
**数据边界：** 收盘价不伪装成实时行情；合成示例不会写回持仓和 Watchlist。

> 市场事实 → 4 条结构主题 → 6 个状态标的交叉映射 → 3 个值得验证的候选 → 1 个需要策略审计的问题 → 0 个自动交易动作

| 层级 | 结论 |
|:---|:---|
| 市场环境 | 混沌偏防守；指数稳定，但高估值低验证资产退潮 |

| 衰退主题 | 只有模型曝光、缺少订单验证的泛 AI 概念 |
| 今日纪律 | 价格只决定研究顺序；事实和 Profile 才能决定动作 |

## 价格层与事实层的冲突

### DEMO-A：价格走强，但证据仍不完整

- **价格告诉我们的：** 市场正在提高关注度。
- **价格不能告诉我们的：** 客户验证是否会转为量产订单，新增收入是否有足够毛利。
- **正确路由：** “调研一下 DEMO-A”，而不是直接生成买入结论。

### DEMO-H：价格偏弱，但行业方向仍在强化

- **行业告诉我们的：** 赛道需求没有被整体证伪。
- **个股告诉我们的：** 公司可能存在独立的交付或竞争问题。
- **正确路由：** 复现原论点和失效信号，交给策略内核做持有审计。

> **问题，不是答案：** 如果 DEMO-H 的行业论点仍成立，但公司连续弱于同类且验收时间再次推迟，当前 Profile 应以“基本面失效”“时间失效”还是“相对强度失效”为主要裁判？
