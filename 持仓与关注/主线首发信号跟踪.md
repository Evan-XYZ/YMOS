# 主线首发信号跟踪（Sector Ignition Signal Tracker）

> 板块级「首发信号」的机器可读真相源。
>
> **它解决的问题**：当多只个股同时指向同一个细分板块时，如果你还按老路径走
> （逐只跑完整深研 → 才敢动），等深研跑完，第一波往往已经走完了。
> 板块刚点火时，**先要判断的是"这条主线真不真、代表权是谁"，而不是"某一只票深研透了没有"。**

---

## 触发定义（SIS，三条要全满足）

某细分板块同时满足：

1. **近 3 日 ≥ 3 只**个股进入你的异动池（涨幅 / 新高 / 大幅波动都算）
2. 组内龙头 **5 日涨幅 > 30%**
3. 有**明确的产业催化**——订单、产能、财报、政策这类**硬催化**；纯情绪/概念不算

> 三个阈值都可以按你自己的市场和风格调，但**必须提前定死**，不能事后调整来迎合已经发生的行情。

---

## 纪律（比表本身重要）

- **SIS ≠ 买入信号。** 它只把你的注意力转到"先定代表权 + 判断现在是第几波"。
- **加速后段 / 退潮：只登记，不追高。** 错过第一波可以接受，追在最后一棒不行。
- 真实买入代表权仍需走 P5（含信念测试）+ P12 + 你自己拍板。
- **生命周期**：主线退潮、代表权已建仓或逻辑被证伪后，把 `status` 改成
  `faded` / `filled` / `invalidated` 并写一句原因，**不删行**——留着复盘才知道自己当时哪里判错了。

---

## 四个角色（判断"第一组资金会买谁"）

| 角色 | 含义 | 特征 |
|:---|:---|:---|
| `anchor` | **中军 / 定价锚** | 大市值、流动性好、机构可配置，市场解释这条主线时绕不开它。通常是先手首选 |
| `beta_leader` | **弹性龙头** | beta 最大、右侧加速的抓手。股性强但波动也大 |
| `choke_point` | **稀缺卡点** | 设备 / 材料 / 耗材里的瓶颈环节，非对称收益。但"稀缺"不等于"现在就买"——要看资金是否已经表达 |
| `value_repair` | **低估值补涨** | 主线确认之后的修复锚，通常最后动 |

---

## 势能阶段

`第一波抢筹初期` → `第一波加速中段` → `第一波加速后段` → `退潮`

判据：龙头「已涨幅 vs 终局粗估」的比值、板块内下跌个股占比、换手是否见顶、
有没有出现高位放量滞涨。**后段和退潮 = 追高必死区。**

## 记录表

```yaml
signals:
  - sector: 示例细分板块
    first_detect: YYYY-MM              # 首次识别为成组异动的月份
    members: [标的A, 标的B, 标的C]      # 组内成员
    leader: 标的A                       # 当前领涨
    leader_5d_gain: "+XX%"
    catalyst: 这条主线的产业催化是什么（要能说清硬在哪，说不清就只是题材）
    us_mapping: 有没有跨市场映射 / 共振还是背离（没有就写"无"）
    roles:
      anchor: 标的A                     # 中军 / 定价锚
      beta_leader: 标的B                # 弹性龙头
      choke_point: 标的C                # 稀缺卡点
      value_repair: null                # 低估值补涨，没有就 null
    stage: 第一波抢筹初期
    verdict: 一句话裁决（这条主线现在算什么、依据是什么）
    action: 现在该做什么（先手 / 只登记击球区 / 只当温度计）
    first_wave_missed: false
    status: active                      # active / faded / filled / invalidated
    last_update: YYYY-MM-DD
    note: 补充观察，尤其是"和上次判断相比变了什么"
```

## 每次更新时问自己三句

1. **组内表达广度**在扩大还是收缩？（只剩龙头单只在动 = 主线在死）
2. 大盘切换主线的那天，**这一组有没有参与**？（切换日零表达是很强的退潮信号）
3. 我现在想动手，是因为**条件成立**，还是因为**怕踏空**？

> 第 3 条如果答不干净，就去决策台走一遍门禁，别直接下单。
