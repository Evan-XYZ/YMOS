## 6. 与持仓和 Watchlist 的关系

- 持仓与关注身份以 `持仓_状态机.md`、`Watchlist_状态机.md` 为准，本文件不重复维护股数、成本或身份。
- 投资雷达和热门观察可以使用本文件解释当前方向，并把信号映射到真实持仓/Watchlist。
- 本文件提到某只股票，不等于自动加入 Watchlist；需要改变身份时必须走标的管理流程。

## 7. 与 Strategy Profile 的边界

| 问题 | 应写在哪里 |
|:---|:---|
| 最近重点看什么、关注哪些事件、报告怎样排序 | 本文件 |
| 当前真实持仓、Watchlist 身份、成本与数量 | 对应状态机或单笔状态文件 |
| 什么证据允许入场、什么时候认错、仓位与风险预算 | `Brain/策略配置/当前策略_Profile.md` |
| 交易计划、Human 门禁和实际执行记录 | `Brain/交易计划/`、`Brain/买入卖出决策/`、`Brain/决策审计/` |

两者不自动同步，也不存在覆盖关系：

- 本文件可以关注 Profile 能力圈之外的方向；投研报告照常展示，并可标注“研究关注，尚未进入已确认策略范围”。
- Profile 激活或修改时，不自动改写本文件。
- 本文件若从 V3 迁移而来并含有仓位、止损、退出等旧规则，只作为历史上下文；需要用于动作判断时，由 Agent 单独整理成 Profile 草案并经 Human 确认。

## 8. Agent 更新规则

1. 用户可以直接说“最近重点看 AI 算力和机器人”“暂停跟踪某方向”“下周重点盯某事件”。
2. Agent 先读取当前文件，给出拟新增、修改、失效的条目摘要；用户确认后再写入。
3. 不因单日报告自动修改关注方向，不从价格上涨反推用户偏好已经改变。
4. 更新本文件不触发 Profile、持仓、Watchlist、交易计划或定时任务变更。
5. 每次更新保留必要的复核窗口；到期后提示复核，不静默删除。
