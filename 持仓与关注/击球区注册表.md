# 击球区注册表（Strike Zone Registry）

> 你所有「等它跌到这里我才考虑」的价格区间的**机器可读真相源**。
>
> **消费方**：日常价格扫描 / 投资雷达在跑的时候，拿当日价格对照本表。命中 → 报告「🎯 击球区命中」+ 生成盘前预备卡。
>
> **维护规则**：每次 P9 / P17 / P5 深研产生或更新了击球区，**必须同步本表**。
> 价格结构失效、或标的已买入/已剔除后，把 `status` 改成 `expired` / `filled` 并注明原因，**不要删行**——
> 删掉就看不到自己当初为什么等、后来又为什么放弃了。
>
> **纪律（最重要的一条）**：**区间命中 ≠ 买入信号。**
> 命中只触发「盘前预备卡」；`trigger_conditions` 没验证的要标注「区间命中、条件未验证」；
> 真实买入必须走 P5（含信念测试）+ P12 + 你自己拍板。

---

## 为什么要有这张表

不写下来的击球区等于没有。人在盘中会做两件相反的蠢事：

1. **跌到位了却不敢买**——因为当初没写清楚"跌到多少、满足什么条件我就买"，临场全靠情绪。
2. **没跌到位就先买了**——因为"看起来差不多了"，而没有一个白纸黑字的区间来拦你。

这张表把「买点」从**盘中的感觉**变成**盘前就定好的条件**。它和决策台是一对：
表负责说"什么价位值得看"，决策台负责说"看了之后能不能真的动手"。

---

## 字段说明

| 字段 | 含义 |
|:---|:---|
| `code` / `name` | 标的代码与名称 |
| `type` | 这个区间是干什么用的：新建仓候选 / 加仓区 / 减仓区 …… |
| `watch_zone` | **观察区**：进入后开始留意，不代表可以动手 |
| `audit_zone` | **审计区**：更深的回踩位；进入后才值得跑完整买入审计。没有就填 `null` |
| `trigger_conditions` | 除了价格之外，还必须同时成立的条件（这一栏才是真正的门） |
| `evidence_needed` | 还缺哪些证据才敢下手——**诚实填写，这是防自欺的关键** |
| `source` | 这个区间是哪份调研得出的，方便回头复核 |
| `status` | `active` / `expired`（结构失效）/ `filled`（已买入） |

## A 股

```yaml
a_share_zones:
  - code: 000000.SZ
    name: 示例标的
    type: 新建仓候选
    watch_zone: [90, 95]          # 第一观察 / 回踩承接区
    audit_zone: [82, 88]          # 更深的回踩审计区；没有就写 null
    trigger_conditions: "回踩有承接 且 下季度订单/毛利率兑现未被证伪"
    evidence_needed: "核心业务收入占比、订单能见度、毛利率趋势、经营现金流"
    source: 持仓与关注/动态Watchlist/<标的目录>/个股基础知识库.md
    status: active
```

## 使用节奏建议

- **每次深研之后**：立刻回填一行。趁着刚想清楚，把区间和条件定死。
- **每周**：清一遍 `status`。逻辑已经变了的，标 `expired` 并写一句为什么。
- **命中之后**：先看 `trigger_conditions` 和 `evidence_needed`，**不要先看 K 线**——
  顺序反了，你就是在给已经想买的决定找理由。
