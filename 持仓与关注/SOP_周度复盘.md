# SOP：周度复盘（账户攻防审计）

> 暗号：`跑一下周度复盘`
> 模块：持仓与关注/（账户与决策层）
> v1.0（2026-07-15）：从 7 月回撤复盘反推出的制度补丁——账户资金曲线定下周攻防基调。

---

## 一句话定位

**每周日晚用账户资金曲线 + 本周错误清点，定下周攻防基调（risk on 正常打 / 保果实止盈为主 / 降敞口不开新仓 / 熔断止血），并把结论喂给下周每天 16:45 的投资雷达。**

- 投资雷达（日度）看"明天怎么打"，周度复盘（周度）看"下周该不该打、用多大敞口打"
- 周度基调是日度定调的**上位约束**：雷达的次日敞口偏置不得高于本周基调（例：周基调=降敞口，则雷达即使判 Risk on 也最多"持平"，并说明冲突）

## ⚙️ 执行步骤

### Step 1：加载输入

```
持仓与关注/账户资金曲线.md                 # 核心输入：本周逐日记录 + 周度汇总历史
持仓与关注/持仓_状态机.md
Eyes/投资雷达/YYYY-MM/ 本周 5 份雷达报告    # 每日收盘审计 + 次日定调的兑现情况
Eyes/Whats_Hot/YYYY-MM/ 本周报告（可选）
<你的纪律清单文件>                          # 当前红线清单的来源（见下方说明）
```

### Step 2：账户资金曲线定性

- 本周盈亏：`盈利 / 亏损 / 持平`，回撤幅度
- 最近 2-4 周曲线形态：`顺（稳步上行）/ 一直亏（连续回撤）/ chaos（震荡）`
- **连续不盈利周数**：≥3 → 熔断（下周基调强制=止血、降频、禁开新仓）
- **新高自检**：账户在/接近历史新高 → 触发**新高三禁**（禁加本金、禁放大仓位、禁开非计划新仓），基调向"止盈/减敞口"修正

### Step 3：曲线状态 → 下周攻防基调（核心输出）

| 曲线状态 | 下周基调 |
|:---|:---|
| 连续 1-2 个月盈利、几乎无回撤 | **保住胜利果实**：提防 risk off、止盈为主、减敞口 |
| 本周仍盈利、无明显回撤 | **可继续 risk on**：按三板斧正常打 |
| 本周亏损 / 预期外情绪 / 连续触发止损 | **降敞口**：不开新仓，只管理存量 |
| 连续 ≥3 周不盈利 | **熔断**：止血、降频、空仓等待 risk on 重启 |

### Step 4：本周错误清点（红线审计）

对照你自己的红线清单逐条自检（下面几条是常见项，请替换成你自己的）：

- [ ] 止损/止盈后日内买回？
- [ ] 开盘冲动跳过新高买卖决策台 / 不在前一日计划内的买入？
- [ ] risk off / 退潮日逆势加仓、开新仓？
- [ ] 业绩预告/订单确认就重仓（跳过市场确认门）？
- [ ] 资金曲线新高时加本金/放大仓位？
- [ ] 持仓数量超限（>3）、混进"等估值提升"的非强趋势票？

每条命中的错误：写一行归因 + 估算代价；挑**最重要的一条**作为"下周唯一改进点"。

### Step 5：雷达兑现度回看（可选，轻量）

- 本周 5 份雷达的次日定调（风偏预判/敞口偏置）与实际盘面的匹配度如何？
- 自己是否按"开盘只执行"守住了计划？没守住的是哪天、什么诱因？

### Step 6：生成周度复盘报告

**输出路径**：`持仓与关注/投资复盘/周度/周度复盘_YYYY-MM-DD.md`（日期=周日）

```markdown
# 周度复盘 - YYYY-MM-DD（第 N 周）

## 📉 账户曲线审计
- 本周盈亏 / 回撤 / 连续不盈利周数 / 曲线定性
- 新高三禁自检 / 熔断自检

## ⚔️ 下周攻防基调（核心输出）
- 基调：risk on 正常打 / 保果实止盈为主 / 降敞口不开新仓 / 熔断止血
- 一句话理由
- 对下周雷达的约束：次日敞口偏置上限 = [基调档位]

## 🚫 本周错误清点
| 红线 | 是否命中 | 归因 | 估算代价 |
- 下周唯一改进点：[一条]

## 📊 雷达兑现度回看
- 定调 vs 实际 / 计划执行率 / 破功日与诱因

## 📌 待人工确认项
```

### Step 7：写回

1. `持仓与关注/账户资金曲线.md` 的「周度汇总」表追加一行（周盈亏 / 连续不盈利周数 / 曲线定性 / 下周基调）
2. 下周基调供每日 16:45 投资雷达 Step 5.6 读取（雷达读「周度汇总」最新行作为上位约束）
3. 若产生新纪律/新教训 → 提示落盘到你自己的笔记库，并考虑补进红线清单；**不自动写**

---

## ⚠️ 边界与反模式

**周度复盘不做**：
- 不做个股研究/策略分析（那是 P 系列的事）
- 不给具体买卖指令（基调是敞口档位约束，不是下单指令）
- 不在周中随意改基调（盘中觉得"行情变了"→ 最多降基调，升基调必须等下一次周度复盘或人工显式确认）

**反模式**：
- 只看盈亏数字不清点红线错误（复盘的价值一半在错误归因）
- 连续盈利时跳过复盘（恰恰是保果实/新高三禁最该触发的时候）
- 把周度基调当摆设，雷达/盘中随意突破上位约束
