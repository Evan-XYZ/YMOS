# 关注方向维护 SOP

> 暗号：`更新我的关注方向` / `最近重点看 [方向]` / `暂停关注 [方向]`
> 写入：`持仓与关注/当前关注方向与投资偏好.md`

## 1. 定位

用一次轻量对话维护投研层的当前注意力，不要求用户配置 Strategy Profile，也不改变任何持仓、Watchlist 或交易规则。

本 SOP 只回答：

- 最近重点看什么；
- 为什么现在看；
- 哪些关键词、事件、跨市场或产业链信号值得跟踪；
- 何时复核或暂停；
- 日常报告应怎样排序和呈现。

## 2. 输入

1. 用户本次明确表达。
2. 现有 `持仓与关注/当前关注方向与投资偏好.md`；缺失时以仓库模板结构新建。
3. 用户点名需要参考时，读取最近市场洞察、投资雷达、热门观察或对象知识库；不得因为报告出现热点就自动添加关注。
4. 持仓与 Watchlist 状态机只用于核对身份，不把身份变化写回本文件。

## 3. 执行

### Step 1：识别变更类型

分为：新增方向、调整优先级、补充证据关键词、增加事件窗口、修改跨市场映射、暂停/恢复、修改阅读偏好。

### Step 2：给出最小草案

先向用户展示：

```text
拟新增：
拟修改：
拟暂停/恢复：
复核窗口：
不会改变：Strategy Profile / 持仓 / Watchlist / 交易计划 / 定时任务
```

若用户只说了一个方向但没有理由或窗口，可以给出待确认空位；不得用模型常识替用户写成已确认偏好。

### Step 3：Human 确认后写入

只有用户明确确认草案后才更新文件。保持原有未涉及条目，避免整文件重写造成信息丢失。更新 `最后更新`，并为临时关注保留复核窗口。

### Step 4：冲突与旧 V3 内容

- 本文件与 Profile 的关注范围不同，不构成策略冲突；可以标注“研究关注，尚未进入已确认策略范围”。
- 若旧 V3 文件含入场、仓位、止损、加减仓或退出规则，不删除原文。先备份，再把这些内容列为“待迁移策略候选”；只有用户另行进入内核配置，才生成 Profile 草案。
- 本文件不作为动作级结论的兜底 Profile。

## 4. 验收

- 变更可以回答“现在重点看什么、为什么、验证什么、何时复核”。
- 没有新增买卖、仓位、止损或退出规则。
- 没有修改持仓/Watchlist 身份或 Strategy Profile。
- 用户未确认时没有写盘。
- 投资雷达和热门观察可以直接读取更新后的条目做排序和关联。
